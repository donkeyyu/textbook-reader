# 03: 查看教材信息、移出与撤销

**Parent:** [书架、教材管理与启动恢复规格](../spec.md)

**What to build:** 读者通过书籍菜单确认教材版本、移出暂时不用的教材，并可撤销或重新添加。操作只改变书架入口，保留阅读记录、笔记和个人补充。

**Blocked by:** [01：首次进入书架、添加教材并开始阅读](01-shelf-and-reading.md)。

- [x] 每本书的更多菜单提供“查看教材信息”和“移出书架”；展示真实版本信息，不将同名书视作同一教材版本。
- [x] 移出后当前书架和刷新后的书架均不再显示该书；最后一本移出后恢复可操作的空书架。
- [x] 移出后提供撤销，撤销恢复同一教材且不产生重复项。
- [x] 重新添加同一教材版本后可继续既有阅读位置，并保留已保存笔记和个人补充。
- [x] 移出不删除教材库资源，不调用个人内容删除操作，不清空阅读历史；其他教材的成员关系及数据不受影响。
- [x] 移出或撤销保存失败时显示错误，不伪报成功，不破坏原记录；读者仍可重试或继续阅读。
- [x] 菜单、信息窗口、撤销在桌面、手机和键盘下可操作；关闭后焦点回到有意义的位置。
- [x] 通过隔离浏览器数据验证查看信息 → 移出 → 撤销，以及移出 → 重新添加 → 打开原阅读位置；核对已保存个人内容保留，不修改真实用户笔记。
- [x] 沿用已有个人内容测试入口验证数据保留；不以任务 04 的书架登录入口为前置条件。
- [x] 更新教材管理交互说明，运行受影响的既有检查并记录结果。
