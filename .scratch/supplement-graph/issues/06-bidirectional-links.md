# 06: 双向导航个人引用并在图中显示连线

**Blocked by:** 03：从教材补充进入可探索的完整图；05：在笔记和个人正文中建立稳定的节点链接。

**What to build:** A 引用 B 保存后，图出现一条无箭头个人连线，B 可查看来自 A 的引用并导航返回；编辑或删除引用时，图与详情按剩余有效引用同步更新。

- [ ] 不改写被引用节点正文；反向列表反映真实引用方向。
- [ ] 重复引用和双方互引聚合为一条个人连线，删除最后一处才移除；删除目标后失效引用不生成有效边。
- [ ] 默认关联与个人关联可区分，个人连线撤销不影响默认关联；自引用不画自环。
- [ ] 只在保存成功后更新持久化关联；失败或较早保存完成不能错误覆盖较新视图状态。
- [ ] 浏览器演示双向导航和连线变化；数据测试覆盖多处引用逐次删除、双方互引与目标删除，刷新后结果一致。

规格覆盖：US21–25、30、34–35；T5–6。不得另建与正文绑定不一致的独立可编辑边来源。

整体验证责任：本任务与另一项（06／07）均完成后，由最后完成者补验“教材 → 图 → 笔记链接 → 分屏定位 → 刷新恢复”全路径，并在两项的 Comments 中记录结果。

依据：[详细规格](../spec.md)、[审查记录](../review.md)。规格中的实施建议仍是工程建议，不提升为用户已确认的技术选型。

验证：运行受影响测试、类型检查与构建，并完成本票浏览器路径；仅为存储迁移和链接身份补充数据层测试。
