# 03: 按需展开方法并保留返回上下文

**What to build:** 让读者先读教材与知识回顾，自主展开思路与方法；查阅关联后回到原来的展开状态。

**Blocked by:** None (can start immediately)

**Spec:** [教材预习与复习规格](../spec.md) — C1–C3；用户故事15–23。

## Acceptance criteria

- [x] 所有习题引导首次打开时方法默认收起，入口明确；考查知识点、注意事项、相关知识及必要说明可见，四项内容不丢失。
- [x] 点击与键盘均可展开、收起，控件表达展开状态；原教材例题解答和非习题概念、推导说明保持可读。
- [x] 方法开合不重置原页、不丢失未保存笔记；单条入口和密集入口的题目选择与切换均正常。
- [x] 展开方法后查阅关联再返回，恢复来源解读、方法状态、教材区域及有意义的焦点；直接重新打开或刷新后重新进入默认收起。
- [x] 用已有题目数据完成端到端演示，扩展现有关联返回浏览器检查，验证多层返回与关闭后的状态；完成受影响测试、类型检查与构建。
- [x] 本任务交付呈现行为；六章任务分别负责默认可见内容审核。不得因文字尚未审核而宣称全部题目均已保留自主判断空间。

## Boundaries

复用现有模块与检查，无需广泛预重构。只修改本票责任范围，保留并行工作和既有未提交改动。产品票包含必要实现与验证，内容票包含审核、修订与展示核验，观察票包含真实记录和问题复核。范围限教材解读，不增加诊断、作业辅导或课外培训。
