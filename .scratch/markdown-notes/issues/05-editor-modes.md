# 05: 正文三模式与文件头独立切换

Status: ready-for-agent
Category: enhancement

**What to build:** 同一篇本地 Markdown 支持编辑、只读预览和实时预览，在编辑与实时预览模式下独立选择文件头源码或可编辑属性预览；只读预览中属性和位置仍可查看。

**Blocked by:** 02：外部编辑与自动保存冲突保护

## Acceptance criteria

- [ ] 默认实时预览与属性预览；编辑与实时预览下文件头两种展示独立切换，修改同一份数据，切换保留草稿和可继续编辑的现场。
- [ ] 编辑显示 Markdown 源码，只读预览的正文、文件头属性和 anchors 均不提供修改控件，但仍显示属性与位置，实时预览可在渲染中编辑；正文为单一连续纸面，不拆成解读与个人笔记两套输入。
- [ ] 文件头支持新增、修改和删除用户属性；同库同名属性共用显示类型，类型不匹配提示但不强制转换文件值。顶层用户属性与 `_textbook` 隔离，同名不覆盖，只有内置 anchors 参与定位；同层重复键提示并保留源码草稿，修复前暂停保存与可视化写入。
- [ ] 内置对象在属性预览中隐藏，笔记信息可只读查看 ID 和时间；源码默认折叠 `_textbook`，可展开查看完整内置对象，未知属性、注释与顺序尽量保留。
- [ ] YAML 无效时显示错误位置、保留源码草稿、暂停自动保存和可视化写入；修复后可继续；不要求按原样保存无效 YAML。
- [ ] 实现前固定理解、提示、注意、个人补充的 callout 标识及内容转换规则；支持折叠，未知类型仍保留标题和正文。
- [ ] 公式、列表、链接及 callout 可正确渲染，HTML 不执行；公式与必要字体资源可离线使用，具体目标导航由 08 和 10 承接。
- [ ] 模式偏好按库保存；重新打开后保留选择，不影响其他库的内容或本机窗口状态。
