# 补充节点图与个人笔记关联

## Problem Statement

现有解读依附教材位置，适合连续阅读。读者需要从正在查看的 supplement 出发，在同一张图中探索其他补充，并通过个人笔记建立自己的联系。现有知识关联指向教材位置，不能直接当作 supplement 之间的边；个人笔记与个人补充也使用不同的数据结构。若仅增加图形渲染，会产生悬空目标、重名误连和个人内容丢失等问题。

## Solution

在保留教材连续阅读的基础上增加补充节点图。一条 supplement 对应一个节点；图包含当前教材的全部默认补充及其个人节点，进入时聚焦当前节点。节点按现有类型着色，支持平移、缩放和选择。默认关联可投影为节点间的联系；只指向教材原文的关联继续提供原文跳转。

用户在“我的笔记”或个人节点正文中输入 `[[节点名称]]`，通过带章、节信息的候选选择目标，形成可双向导航的个人关联。图旁显示解读；定位教材时默认同时显示图和教材。桌面采用可调宽度的左右分屏，窄屏切换视图。数据当前存入本地数据库，默认内容只读，个人内容私有。

## User Stories

1. As a 读者, I want 从当前 supplement 进入图并看到它居中, so that 我知道探索的起点。
2. As a 读者, I want 图中包含当前教材全部 supplement 和个人节点, so that 我能跨章节探索。
3. As a 读者, I want 平移和缩放图, so that 我能查看屏幕外的节点。
4. As a 读者, I want 节点按类型着色并能查看类型名称, so that 我能辨认内容用途。
5. As a 读者, I want 每条 supplement 保持独立节点, so that 同名内容仍保留各自上下文。
6. As a 读者, I want 点击节点查看解读而不滚动教材, so that 我能连续探索关联。
7. As a 读者, I want 查看节点间的默认教材关联及其理由, so that 我理解为什么需要回顾目标。
8. As a 读者, I want 没有 supplement 的目标仍可跳转原文, so that 图不会使已有依据丢失。
9. As a 读者, I want 定位教材时自动分屏, so that 我能同时对照图和原文。
10. As a 读者, I want 调整桌面分屏宽度, so that 当前阅读内容有足够空间。
11. As a 读者, I want 隐藏或关闭任一视图并重新打开, so that 我能集中阅读且继续原任务。
12. As a 窄屏读者, I want 切换图和教材并保留位置, so that 我无需使用拥挤的左右分屏。
13. As a 读者, I want 自由滚动教材时图保持不动, so that 探索现场不会被打断。
14. As a 读者, I want 题目解读保持现有方法按需展开规则, so that 图入口不改变阅读层次。
15. As a 读者, I want 在默认 supplement 的“我的笔记”中输入双括号链接, so that 我能建立个人联系。
16. As a 读者, I want 在个人节点正文中使用相同链接语法, so that 创建联系的方式一致。
17. As a 读者, I want 输入双括号时搜索节点候选, so that 我不用记住完整名称。
18. As a 读者, I want 候选显示章、节以及必要的位置或摘要, so that 我能区分同名节点。
19. As a 读者, I want 选定的链接在目标改名后仍有效, so that 整理名称不会破坏联系。
20. As a 读者, I want 找不到目标时主动创建个人节点, so that 我能补充新想法而不产生自动空节点。
21. As a 读者, I want 从被引用节点查看并返回引用者, so that 我能双向探索个人联系。
22. As a 读者, I want 自动反向展示不修改目标笔记, so that 我的文字保持原样。
23. As a 读者, I want 双方均引用时删除一处仍保留连线, so that 图准确表达剩余联系。
24. As a 读者, I want 删除最后一处个人引用后撤销个人连线, so that 修改笔记能更新图。
25. As a 读者, I want 个人引用的修改不影响默认教材关联, so that 教材依据仍可使用。
26. As a 读者, I want 创建不绑定原文位置的个人节点, so that 我能记录跨段落的想法。
27. As a 读者, I want 创建时默认归属当前章节且能调整或选未归属章节, so that 内容仍能在当前教材中整理。
28. As a 读者, I want 个人节点使用“我的补充”的颜色, so that 我能识别个人内容。
29. As a 读者, I want 编辑和删除自己的节点与笔记, so that 我能持续整理理解。
30. As a 读者, I want 已删除节点的引用明确提示失效, so that 我不会误入同名内容。
31. As a 读者, I want 默认内容当前保持只读, so that 个人记录与默认补充分开。
32. As a 读者, I want 个人内容只在本地保存且不公开, so that 我保有自己的学习记录。
33. As a 既有读者, I want 现有笔记和个人补充完整迁入新存储, so that 升级不会丢失已有工作。
34. As a 读者, I want 刷新后读取已保存内容与有效链接, so that 我能继续学习。
35. As a 读者, I want 保存失败时保留草稿并提示原因, so that 我可以重试或保全内容。
36. As a 多标签页读者, I want 旧标签不能覆盖新记录, so that 我的修改不会悄悄丢失。
37. As a 键盘使用者, I want 搜索、选择节点和操作面板可通过键盘完成, so that 我能完成同样的阅读路径。

## Implementation Decisions

### 确认状态与模块责任

以下产品行为来自已确认访谈；具体工程方案单独标为“实施建议”，不作为用户已选择的技术事实。沿用教材查询、个人内容、Markdown 编辑与预览、阅读会话等现有责任。新增图展示与图数据投影；存储和链接解析由内容侧处理，绘图模块只接收节点、边及选择事件，不承担内容编辑或数据库写入。

Pixi.js 是用户提出的技术偏好。实施建议采用它实现渲染，并参考 family-tree 的 d3-force 布局、拖动、缩放分级标签和邻居高亮。只复用交互模式，不搬入家族人物模型、权限体系或大图发布管道；不宣称参考项目已验证本项目性能。

发布任务时 DonQ 补充：图需考虑节点距离和拖动效果，可参考 Obsidian 源码或 family-tree 实现效果。优先使用已可查的 family-tree；Obsidian 源码仅在实际可获取时参考，不把获取源码作为任务阻塞条件。验收包括连线距离、排斥与碰撞间距、缩放下的标签可读性；拖动时节点跟随指针、连线同步更新，不误触点击或平移，释放后平稳收敛且不重置视野。参数由本册实测确定，保留参考来源及效果记录，不新增跨刷新布局保存要求。

### 节点、教材位置与章节

- 默认节点保留既有 supplement ID、教材身份、标题、正文、学习作用、题目引导及位置引用。个人节点保留既有身份；新节点生成稳定身份。不同教材、不同来源的身份不能碰撞。
- 默认节点类型沿用现有显示分类：概念与性质、方法与推理、题目引导、回顾与探究。个人节点统一使用“我的补充”。颜色之外保留可读取的名称信息。
- 教材位置仍独立记录。位置的文件页序、印刷页码和区域不合并成节点身份；自由节点不伪造位置，也不提供无效的定位动作。
- 当前教材的全部节点进入图，包括未连线的节点。教材入口隐藏或类型筛选不自动删减全图，这是“完整图”要求的实现解释，不新增图筛选功能。
- 自由节点仍属于当前教材；章、节归属可空，不等于原文坐标。默认使用明确的当前章节；当前位置无法确定章节时使用未归属，不猜测。
- 同名节点允许共存。候选显示章、节；同节仍重名时补充教材位置或内容摘要。身份绑定不得依靠标题或页码。

### 默认关联的图投影

- 保留现有关联的方向、目标教材位置、关系说明及阅读目的。
- 目标位置对应 supplement 时才生成默认节点间关联；目标只有原文时，在详情中保留原文入口，不生成空节点、不删除关联、不按最近坐标猜测目标。
- 当前数据不保证类型层面的位置与 supplement 永远一对一。实施建议：出现同一目标位置对应多条 supplement 时，详情让读者选择；图投影保留该位置对应的全部目标节点，并保留共同的教材位置依据，不任选一条。
- 默认关联与个人关联保留各自来源。两者连接同一对节点时仍能区分；删除个人引用不能删除默认关联。具体线型可由实现选择，默认关联的方向与理由须在详情可查。

### 笔记链接及身份

- 默认节点的“我的笔记”属于该节点，不另外生成笔记节点。个人节点正文同样可发起链接。
- 输入 `[[` 提供当前教材节点候选，选定后以节点稳定身份绑定。显示仍为 `[[节点名称]]`；存储须保留标题文本与目标身份的对应，不在每次渲染时重新按标题猜测。
- 每个已绑定引用实例分别保存目标身份，同一笔记中的同名引用可指向不同节点。普通文字编辑、链接删除和撤销不得交换其目标。复制为纯文本再粘贴时按未绑定链接处理，重新选择目标，不继承无法核实的绑定。
- 实施建议：手输或粘贴、尚未绑定的链接提示选择候选或创建节点；不静默绑定第一个重名项。显式创建成功并保存后才能成为图中节点。取消创建不留下空节点。
- A 引用 B 后，图显示一条无箭头的个人连线。B 显示来自 A 的引用并可返回 A；不向 B 的 Markdown 自动插入内容。
- 关联的依据是仍存在的有效引用。重复引用、双方互引均聚合为同一条个人连线；只在最后一处有效引用被删除后撤销。反向引用列表按真实引用方向列出，不捏造双方都写过引用。
- 改名不改变目标身份；被引用名称可更新显示，但不能使引用转向其他同名节点。删除目标后保留足以提示失效的引用身份，不自动重建或重绑。失效引用不生成有效图边。
- 实施建议：代码块、行内代码和转义的双括号视为文本；未闭合双括号保留为草稿文本。首版只实现节点链接，不引入嵌入、标题锚点或 Obsidian 插件语法。
- 实施建议：允许正文引用自身，但图不画自环，避免产生无助于导航的线；引用文字仍可定位自己。
- 保存正文与其已绑定引用须保持一致；输入中的临时变化不应先修改持久化连线。保存成功后更新图与反向引用，保存失败继续保留草稿。

### 本地数据库与迁移

- 用户确认当前本地保存，后续整体迁移；不加入账号、服务器或跨设备同步。私有表示本地个人内容不主动上传、发布，不表示提供额外的本机加密或浏览器隔离。
- 实施建议使用浏览器 IndexedDB，集中保存默认补充、个人节点、笔记及链接身份，保留教材位置查询与静态页图资源。不引入服务端数据库或通用仓储框架。
- 默认 JSON 作为发布内容的导入源，数据库作为本地运行时节点数据源。教材阅读与图使用同一批节点身份；不让两套独立内容逐渐分叉。
- 导入按教材身份与内容修订执行，可重复运行；同一默认节点不重复创建。更新默认内容仅更新默认记录，个人笔记、节点、关联不可被覆盖。被移除的默认目标也应明确失效，不按同名项重绑。
- 迁入旧个人数据时保留 ID、标题、Markdown、页序、区域及按默认 supplement ID 保存的笔记。旧数据无章节归属时由已核对目录映射；无法确定则未归属。
- 导入、迁移和完成标志在事务成功后生效；失败不留下已完成标志。验证成功前不删除旧数据。重启重试不得重复节点，也不得覆盖新数据库中已经更新的个人内容。
- 存储切换须覆盖仍运行升级前代码的标签页。迁移后发生的旧存储写入不得静默遗漏，也不得覆盖新库较新的内容。实现须阻止旧写入并保全草稿，或检测旧存储变化并保全后到内容；冲突时保留两边内容并给出可操作提示。仅有迁移完成标志不能作为忽略旧存储变化的依据；若采用写入隔离，须验证现有旧代码确实受约束，不能只增加旧代码不读取的标志。具体方案由 02 记录，不要求自动合并或新增同步、导出功能。
- 延续旧标签不能覆盖新修订的约束。冲突或空间不足等写入失败时，保留草稿并提供明确提示与重试路径。读取失败不可写入空数据覆盖已有内容。
- 若采用异步数据库，编辑器保存接口须等待持久化成功后才能标为已保存。保存期间的新输入仍是未保存内容；较早完成的请求不能清除较新的草稿或错误。逐次自动保存可串行或合并，但最终写入必须对应最新有效修订，切换节点和关闭视图不得丢弃待保存内容。
- 不要求此次实现导出界面或未来同步架构。稳定身份、存储版本和迁移规则为将来整体迁移保留必要信息。

### 阅读、图和分屏状态

- 从已选 supplement 进入图时，将它置于可读比例的视野中心；不为了全图同时入屏而缩成不可读的点。全图数据存在，屏幕外内容通过平移缩放查看。
- 实施建议提供教材工具栏的图入口和节点搜索，未选节点时显示全图概览，不假造当前节点。图可拖动节点；布局参数按本册数据验证，不作为固定产品要求。
- 点击节点只切换解读。题目方法仍按现有默认收起规则，个人编辑草稿继续受保护；不能用节点切换绕过保存失败提示。
- 点击“定位教材”打开桌面分屏并定位原文，保留图视野；只有原文的关联目标也使用相同跳转保护。跳转加载失败保留来源并可重试。
- 桌面图与教材左右分屏，分隔条可调；解读面板复用现有内容与编辑能力，不强制增加第三个常驻阅读列。窄屏使用图／教材切换。
- 隐藏、关闭、重开和窗口尺寸变化在会话内保留图视野、教材阅读位置及草稿；不能让两个阅读视图同时关闭后无恢复入口。
- 教材滚动不自动移动图。图节点选择也不自动滚动教材。原有关联返回与定位规则继续成立。
- 跨刷新只承诺恢复已保存数据及现有教材续读位置；图视野、拖动布局、解读展开、关联返回栈不新增跨刷新恢复要求。
- Pixi 图需要可经键盘完成的搜索和节点选择路径；面板关闭后焦点回到有效入口。避免仅靠节点颜色表达类型。Markdown 继续不执行原始 HTML。

### 数据契约与一致性（实施建议）

以下是必须保留的信息及约束，不要求一行对应一张表，也不规定数据库字段命名。

| 对象 | 信息与约束 |
| --- | --- |
| 默认节点 | 教材身份、稳定 supplement 身份、显示类型、完整内容、原文位置引用、导入修订；用户写入不能修改默认正文 |
| 个人节点 | 教材身份、稳定个人身份、标题、Markdown、可空的章／节归属、可空的原文位置、个人修订；原文位置有值时必须完整有效 |
| 节点笔记 | 所属节点身份、Markdown、修订；不因自身存在而生成额外图节点 |
| 已绑定引用 | 来源节点和来源文本、目标稳定身份、可用于失效提示的名称；正文编辑、复制、撤销不能把旧绑定错误地挪给另一处同名文本 |
| 删除目标的引用信息 | 足以保持引用失效和显示原名称；不要求保留已删除的个人正文 |
| 导入记录 | 存储版本、教材身份、默认内容修订、迁移完成标志；仅在对应事务成功后提交 |
| 图投影 | 当前教材节点，以及默认关联和有效个人引用生成的边；不独立保存另一份可变正文 |

公开操作围绕读取当前教材内容、保存个人节点或笔记、解析候选、读取反向引用、删除个人节点和导入迁移。保存操作携带读取时的修订；发生冲突时报告失败而不覆盖。边与反向引用可由已保存内容计算，不要求建立单独可编辑的边数据库。

绑定存储格式由实现选择，但必须通过以下情形：同一笔记两次引用同名的不同节点；只编辑其中一处；在链接前插入文字；撤销和重做；刷新重新读取。若原始文本编辑使绑定无法确定，保留文本并提示重新选择，不静默重绑。

## Testing Decisions

测试观察外部行为与持久化结果，不固定组件结构、力导向坐标、截图像素或内部函数调用次数。主测试边界是现有浏览器阅读入口；仅在浏览器难以稳定制造存储故障和身份冲突时，补充内容存储与链接操作的边界测试。不为每个组件建立重复测试。

已有先例包括教材位置及 supplement 结构检查、个人内容往返存取与损坏保护、跨标签修订冲突，以及浏览器页码导航、分组解读和关联返回检查。浏览器现有关联样本偏向第一章，新路径应增加其他章及个人节点用例。

DonQ 已确认测试边界：以现有浏览器阅读入口验证“教材 → 图 → 笔记链接 → 分屏定位 → 刷新恢复”的完整路径；仅为存储迁移和链接身份增加数据层测试。

## Out of Scope

- 默认 supplement 正文编辑及编辑后转个人节点的实现；该方向已确认，留待后续。
- 跨设备同步、账号、共享发布、服务端数据库、本机加密和通用知识库服务。
- 抽取抽象知识节点、合并同主题 supplement、为只有教材原文的目标生成空节点。
- 自动语义连线、按相同类型自动连线，以及完整兼容 Obsidian 的文件、插件和嵌入语法。
- 新增教材、跨教材图、批量改写教学内容、自动答案及个体诊断。
- 图位置跨刷新持久化、大规模图基础设施和未经测量的性能承诺。
- 通过原型运行证明学习效果；仍需学生使用证据。
