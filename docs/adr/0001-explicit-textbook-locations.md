# 使用明确的教材位置引用，不用印刷页码作主键

教材内容跨页面、题目和步骤关联，同名教材也可能来自不同版本。建议以“教材版本 ID + 位置 ID”引用位置，将源文件身份、文件页序、印刷页码和原页区域分别保存；印刷页码只作核对与展示信息，不能按固定偏移推算。完整设计见 [系统架构](../ARCHITECTURE.md)。

直接使用“第几页 + 坐标”更容易启动，但会在换版、无印刷页码及文件重排时产生静默错链。明确位置引用增加了内容标定成本，却能使来源核对与关联目标校验集中在教材内容 Module；待大量解读依附后，修改此身份规则的迁移成本较高，因此在内容扩充前记录这一取舍。
