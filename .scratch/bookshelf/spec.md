# 书架、教材管理与启动恢复

## Problem Statement

当前应用直接进入单本教材。读者缺少查看和管理所读教材的入口，也无法明确选择下次打开应用时回到书架还是继续阅读。现有阅读位置保存可以恢复同一教材的文件页序和页内相对位置，但尚不能表达“上次离开的是书架”。

读者需要先看到自己的书架，从教材库选择教材；未登录也能阅读，登录后使用已有个人内容同步能力。

## Solution

首次打开应用进入书架。读者从现有教材库添加教材，点击封面或阅读按钮进入阅读页。阅读页提供“返回书架”。后续打开应用恢复上次停留的页面：停在书架就回书架，停在书中就恢复该教材版本及原页阅读位置。

书架支持添加与移出教材。移出只改变书架成员，不删除已保存笔记、个人补充或阅读记录。登录为可选操作，登录成功后保留当前页面。

## User Stories

1. 作为首次使用的读者，我希望先进入书架，以便了解如何选择教材。
2. 作为未登录读者，我希望可以查看书架和阅读教材，以便不必先注册或登录。
3. 作为书架为空的读者，我希望看到“添加一本教材，开始阅读”和添加入口，以便知道下一步操作。
4. 作为读者，我希望从现有教材库添加教材，以便集中访问正在使用的课本。
5. 作为读者，我希望选择时看到书名、封面与教材版本，以便区分同名教材。
6. 作为读者，我希望已经添加的教材显示已添加状态，以便避免重复添加。
7. 作为读者，我希望添加后留在书架，以便继续选择或管理教材。
8. 作为读者，我希望点击教材封面即可阅读，以便快速打开课本。
9. 作为首次阅读某本教材的读者，我希望看到“开始阅读”并从封面开始，以便按教材顺序阅读。
10. 作为已有阅读记录的读者，我希望看到阅读位置和“继续阅读”，以便接着上次的位置阅读。
11. 作为读者，我希望从阅读页返回书架，以便选择其他教材。
12. 作为在书中离开的读者，我希望重开应用时恢复同一教材版本和页内位置，以便继续原来的阅读。
13. 作为在书架离开的读者，我希望重开应用仍在书架，以便自行决定读哪本书。
14. 作为使用不同窗口尺寸的读者，我希望续读仍定位到原页的相对位置，以便缩放或换屏宽后不丢失阅读位置。
15. 作为读者，我希望每本教材分别记住阅读位置，以便切换教材时互不覆盖。
16. 作为读者，我希望通过每本书的菜单查看教材信息，以便确认教材版本。
17. 作为读者，我希望移出暂时不用的教材，以便整理书架。
18. 作为误移出教材的读者，我希望可以撤销，以便立即恢复书架入口。
19. 作为重新添加教材的读者，我希望保留原有笔记、个人补充和阅读记录，以便继续此前的学习。
20. 作为读者，我希望从书架登录账号，以便载入并同步已有个人内容。
21. 作为登录成功的读者，我希望留在当前书架或阅读页，以便不中断正在进行的操作。
22. 作为登录或个人内容加载失败的读者，我希望看到错误和重试入口，以便恢复操作，同时仍能阅读默认内容。
23. 作为正在编辑的读者，我希望返回书架或退出账号时保留现有草稿保护，以便不会无提示地丢失修改。
24. 作为上次教材不可用的读者，我希望回到书架并看到原因，以便选择仍可阅读的教材。
25. 作为本地记录异常的读者，我希望仍能进入书架和阅读，以便记录错误不会阻断使用或损坏个人内容。
26. 作为手机读者，我希望书架、教材选择和账号窗口适合窄屏，以便完成同样的阅读与管理操作。
27. 作为键盘用户，我希望能打开教材、操作菜单和关闭窗口，并看到焦点位置，以便不依赖鼠标。

## Implementation Decisions

### 已确认范围

- 新增书架作为首次入口；后续按最后停留页面恢复。应用启动目的地与每本教材的阅读位置分别保存，不能仅凭“存在阅读记录”判断是否自动打开书。
- 从现有教材库添加、移出书架；不提供个人 PDF 上传。
- 未登录可阅读；登录后同步个人内容。复用现有账号与个人内容行为，不将书架或阅读位置的跨设备同步隐含纳入本次范围。
- 阅读位置继续使用教材版本身份、文件页序和页内相对位置；印刷页码只用于已核对的展示，不作主键，也不通过固定偏移推算。
- 跨刷新只恢复教材原页位置，保持现有恢复范围；不恢复知识关联返回历史、解读面板、筛选、方法展开或未保存草稿。

### 本次实现采用的设计细化

以下为基于会话草案整理的实现默认值，不表示 DonQ 已逐项确认视觉细节。

- 应用入口负责书架与阅读页的切换；书架负责教材列表、添加与移出；阅读器继续负责教材阅读和解读。账号入口在两个页面均可访问，复用已有登录窗口和会话，不建立第二套登录状态。
- 教材库只展示实际可用的教材。当前只有一本可用教材时按一本展示，不虚构其他教材或扩大教材内容制作范围。界面与状态使用教材身份，不把标题当作身份。
- 首次进入默认展示空书架及添加入口。添加成功后留在书架；取消教材选择不改变书架。重复添加不产生重复书籍。
- 书架采用现有浅灰、白色、蓝色和系统字体。封面为主体，下方显示书名、版本及阅读位置，不另套大型装饰卡片。桌面网格、手机两列；长书名换行，交互不依赖悬停。
- 顶部提供“添加教材”和登录／账号入口。每本书提供封面阅读入口、开始／继续阅读和更多菜单；更多菜单包含教材信息与移出书架。空书架保留明确的添加操作。
- 阅读位置优先展示已有印刷页码映射；没有印刷页码时使用明确标注的文件页序，不将两者混淆。
- 阅读页右侧提供带“返回书架”可访问名称的书架图标，工具栏操作按用途分组。完成导航后才更新最后停留页面；草稿保护取消导航时保持阅读页和原启动目的地。
- 移出仅删除书架成员关系，提供撤销。重新添加同一教材版本可使用既有阅读记录和个人内容。不得以“移出”清空内容或删除教材库资源。
- 书架成员及启动目的地首版保存在当前浏览器；它们不作为云端个人内容，也不在登录后被空云端状态覆盖。账号切换继续隔离各账号的笔记与个人补充；旧账号内容不得作为新账号内容展示或保存。
- 登录成功保留当前位置。登录、发送邮件、账号内容载入与失败沿用已有反馈；加载或保存失败不显示虚假的成功状态。登录窗口关闭后归还焦点。
- 主动退出或切换编辑上下文沿用现有草稿保护，取消操作保留原页面和编辑内容；返回书架不得绕过该保护。外部会话变化导致账号切换或退出时，旧草稿保留为带归属提示的待处理内容，供复制或明确放弃；旧请求返回或草稿重试不得写入新账号，也不得将旧保存结果显示为新账号保存成功。
- 正常启动时优先使用有效的最后停留页面。无有效启动目的地时进入书架并展示已保存成员，仅成员为空时展示空状态；目的地为书架时不自动打开最近阅读的书，目的地为阅读页时恢复指定教材版本。
- 上次教材已不可用或不在书架时回到书架并说明原因；教材可用但页位置无效时按现有规则从封面打开。初始化不得先用封面位置覆盖有效旧记录。
- 现有单本阅读记录继续保留。升级后若没有新的启动目的地记录，先进入书架；读者添加并打开原教材时仍可继续原阅读位置，不从历史记录臆测最后停留页面。
- 本地记录损坏或读写失败时保留可用的阅读入口，展示必要提示，不清除或覆盖其他有效记录与个人内容。
- 不新增数据库表、同步 API 或后端教材管理服务作为本次前提。若实现发现既有个人内容能力无法复用，应记录具体差距，不自行扩展同步范围。

## Testing Decisions

- 主测试边界是应用的完整浏览器用户路径。通过页面入口、用户操作、刷新或重开后的可见结果验证行为，不断言组件拆分、内部状态名称、CSS 类或存储字段布局。
- 复用现有浏览器完整阅读路径检查，以及阅读会话、页内位置恢复、个人内容保存与草稿保护的既有测试。优先扩展现有入口，不为每个按钮新建测试层。
- 主路径：首次打开 → 空书架 → 添加实际教材 → 开始阅读 → 滚动 → 刷新／重开恢复 → 返回书架 → 重开仍在书架 → 移出 → 撤销或重新添加 → 恢复阅读位置和已保存个人内容。
- 验证未登录可读；登录后仍在原页面、载入正确账号个人内容；失败可重试；退出或账号切换不串用个人内容。覆盖旧账号保存响应延迟期间发生外部账号变化：响应返回后旧草稿及归属提示仍在，重试不写入新账号，也不显示为新账号保存成功。沿用专用测试账号与隔离测试环境，不修改真实用户笔记。
- 验证未保存编辑下返回书架的取消与继续分支，以及失败保存时的保护；取消操作后重开目的地仍指向阅读页。
- 验证异常：重复添加、教材不可用、损坏或版本不匹配的记录、本地读写失败、旧版阅读记录迁移和初始化不覆盖有效位置。已有书架成员但没有启动记录时，刷新后仍展示已有成员并可打开教材。
- 当单本真实教材不足以验证版本隔离时，使用最小测试夹具增加第二个教材身份；不向正式教材库加入虚构教材。
- 如有必要，沿用现有读取／保存边界补充少量状态决策测试，覆盖书架目的地、教材身份隔离与无效记录回退；不为实现细节新增测试接口。
- 桌面与手机检查完整添加、阅读、返回、移出及登录路径；检查长标题、空状态、窗口焦点、Escape 关闭、触屏和键盘操作。沿用受影响的阅读回归，不把页面无溢出等同于教材原页可读或学习效果有效。
- DonQ 已确认按完整用户路径验证：首次进入书架 → 添加教材 → 阅读 → 重开恢复 → 返回书架 → 移出并重新添加，同时检查登录前后个人内容和草稿保护。规格起草时尚未执行功能测试；后续实施与最终验证结果见 [编排与终审记录](orchestration.md)，不将规格确认本身当作通过证据。

## Out of Scope

- 上传个人 PDF、导入任意文件、在线编辑教材库或制作新增教材内容。
- 书架、最后停留页面与阅读位置的跨设备同步及冲突合并。
- 文件夹、批量管理、拖动排序、学习统计、推荐流或学习进度百分比。
- 删除云端笔记、个人补充或教材资源；清空阅读历史。
- 新增登录方式或重新设计现有个人内容同步机制。
- 新建可分享的教材／位置链接协议。后续若增加直接链接，显式目标应优先于默认启动恢复；本次不以此为交付条件。
- 刷新后恢复整个阅读工作区或未保存草稿。
- 修改教材解读内容、知识关联规则或既有图谱交互。
