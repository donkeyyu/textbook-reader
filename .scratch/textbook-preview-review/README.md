## 执行顺序

- 01–03为三个完整阅读功能，互不硬依赖。
- 04–19为16个连续文件页段，每段24–50项题目引导，共652项。每票完成审核、必要修订、原页核对和展示验证；各章首段另交付共读样本。
- 20在04首批样本及审核记录交付后即可做早期独读与共读观察，不等待04整票、全书审核或新功能。
- 21在三个功能完成后做产品完整路径和真实手机检查，不等待内容线全部结束。
- 22在新功能、六章首批样本与早期观察就绪后做新版复核，不依赖各章剩余页段审核。
- 23汇总双线证据，直接依赖04整票完成，防止样本提前交付后遗漏该页段审核。通过完整任务依赖覆盖全部任务；缺少真人、实机或必要复核时，不得宣称整体完成。

初始可开工的任务是01–19；它们没有任务前置，不代表建议同时修改同一文件。当前执行状态见下文编排记录。各内容票按题目起始文件页序划分责任，跨页题完整核对但不重复认领；同章编辑需协调，避免覆盖其他页段。参与者和设备协调可提前进行，不授权agent主动联系他人。
