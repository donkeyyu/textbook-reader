# 06: 顶部笔记位置与教材框选往返

Status: ready-for-agent
Category: enhancement

**What to build:** 用户在笔记顶部查看和编辑原文位置，从教材框选建立笔记或补充位置，并在教材、笔记全屏和分屏间连续往返。

**Blocked by:** 04：导入 AI 初始内容，直接编辑统一笔记；05：正文三模式与文件头独立切换；08：路径链接、重名选择与反向引用

## Acceptance criteria

- [x] 笔记位置位于正文之前，以列表、下拉和区域预览编辑内置 anchors；不维护独立重复定位数据。
- [x] 教材、章、节候选来自版本对应目录；采用教材到章到节、教材到页面到区域两条依赖链，页面不要求填写章节。
- [x] 有章节无页面可归类，无 anchors 仍可编辑；无效前置条件不使后置字段参与定位，字段仍保留并提示，不自动猜测或修正冲突。
- [x] 文件页序从 1 开始，印刷页码来自核对映射；区域为页面归一化矩形，支持同页多框、跨页多条 anchor，越界输入不用于错误跳转。
- [x] 原页框选可新建统一笔记或添加到当前笔记；点击区域显示边界，拖动调整、移除和取消可正确保存或保持原值。
- [x] 顶部笔记入口、教材位置标记可打开笔记，多篇候选可辨；笔记全屏可展开教材，点击具体 anchor 到对应页面与区域。
- [x] 切换全屏、分屏、调整面板及定位保持未保存内容和阅读位置；移除全部定位不删除笔记，不将无位置笔记定位到虚假页面。
- [x] 断网时已下载教材的定位、框选和返回路径可用。
