# 课本解读多角色评审 · 2026-10-25

方法：三组独立代理模拟角色评审；UI/UX Assessment A=/root/product，技术证据 B=/root/learners。不是实际学生访谈或真人专家背书。评审对象为当前工作区，包含已有未提交改动。本轮未修改源码或需求。

## 主持人结论与目标

方向基本符合预期，核心阅读闭环已经形成；目前更适合带着具体疑问查教材。首次预习与跨次复习支持仍弱，学习价值未获真实学生证据。

目标是帮助学生和家长在教材预习、复习时理解含义、理由、条件和知识联系。预习应支持读懂新概念、发现疑问；复习应支持解释理由、回顾依据、回到原处；家长共读应支持讨论，不要求家长重新讲授或批改。教材内题目可以作为回顾对象，但不将完成作业、个体诊断、一对一培训、课外培优作为目标。

## 模拟角色

分数仅用100分制作讨论假设，不等同先备知识或学习能力。
| 角色 | 当前价值 | 主要风险与最小建议 |
|---|---|---|
| 基础较弱学生，低于60分 | 符号含义和概念边界的具体说明 | 入口需要发现，长段解释不等于理解；少量关键点试验可选复述提示 |
| 中段学生，60–85分 | 理解会算但说不清的理由，关联回顾 | 次日需重新找页；优先验证继续阅读入口 |
| 较强学生，高于85分 | 条件、反例和推理依据 | 部分说明重复、略读效率低；保持按需查看，无需课外难题 |
| 熟悉数学的家长 | 有教材依据的共读与追问 | 易变为朗读解释后问懂了吗；少量可选共读问题 |
| 不熟悉数学的家长 | 减少自己重新讲解的负担 | 页码与术语带来额外门槛；先解决纸书定位，用具体例子说明条件 |
| 数学老师 | 含义、理由、条件有解释增量 | 部分内容应突出真正新增的理由，不重复原教材 |
| 教研员 | 来源、学习动作、题目清单有记录 | AI辅助审核不等于教学效果；需要有限人工抽审和学生复述证据 |
| 产品经理 | 原位解读、关联查阅、返回形成闭环 | 找内容、下次回来两个环节偏弱 |
| UI/UX | 教材主导、按需展开、窄屏上下分区 | 页码语义、首次图标理解、手机可读性需改进或验证 |

## 优先问题

P1：纸书与屏幕页码语义不统一。Reader.tsx:399输入PDF页序，:411常驻仅N/202；Supplement.tsx:99关联优先用印刷页码。建议明确文件页序与课本页码，支持已核实的印刷页码定位。

P2：跨次复习需重新找内容。Reader.tsx:75初始化第一页，笔记持久化但无直接笔记目录。刷新实测回封面。建议先验证继续上次阅读与最小章节入口。刷新记忆在SPEC R4仍待决定，这是场景缺口，不是既有规格违例。

P2：题目方法提示的出现时机。建议保持学生主动选择查阅深度；不引入诊断、答题系统。

P2：手机可读性待验证。390×844时原页宽374px、工具栏104px，原图宽1304px，标记32px。截图超时，不能把容纳布局视为阅读舒适。需真实手机检查正文、分数、几何图和点选。

P2：学习效果证据不足。先用少量关键教材片段，观察学生关闭解释后能否复述条件和理由，以及家长能否借材料完成共读；不以满意度或点击量代替。
