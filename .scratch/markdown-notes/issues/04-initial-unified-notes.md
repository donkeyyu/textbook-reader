# 04: 导入 AI 初始内容，直接编辑统一笔记

Status: ready-for-agent
Category: enhancement

**What to build:** 明确添加教材时导入其 AI 初始笔记包，教材标记打开可直接编辑的同一篇本地笔记，云端初始版本保持独立。

**Blocked by:** 03：下载当前教材并离线阅读；05：正文三模式与文件头独立切换

## Acceptance criteria

- [ ] 实施前固定初始笔记包与当前默认内容的转换、来源 ID/版本映射、重复导入识别方式；复用 05 已固定的 callout 标识与转换规则，原始内容的数学说明及方法折叠意图不丢失。
- [ ] 明确添加教材时导入目录和初始 Markdown，保留标题、正文、类型所需信息、anchors 及 AI 来源引用；不在正常阅读、搜索或扫描时静默批量生成文件。
- [ ] 同一教材位置的标记打开对应统一笔记；桌面不再呈现只读解读加独立附属笔记，用户修改的是本地同一篇内容。
- [ ] 本地笔记 ID 与 AI 来源 ID 分开；云端的来源 ID 与版本对应确定初始内容，来源标识需有可核对的云端记录，不伪造备份成功。
- [ ] 本地编辑、改名与移动不覆盖云端初始版本；未提供恢复、同步或学生笔记云端备份入口。
- [ ] 重复导入、失败后重试以及同名文件存在时不覆盖已有用户修改，不产生无法辨认的重复初始笔记。
- [ ] 不读取后自动迁移旧云端个人笔记或个人节点，旧系统仍可访问；本地初始笔记下载后可离线读取与编辑。
- [ ] 默认知识关联的完整转换由 10 承接；本票保留转换所需来源关系，不用空节点或丢弃原始关系掩盖尚未接入的部分。

## Scope and verification

依据：项目规格 R15（2026-11-01 已确认方案）。实现前阅读当前规格、适用项目约定与技能。当前任务文件创建不授权立即开始实现；执行时仅领取依赖已完成的任务。

本票需完成对应完整用户路径及有意义的失败场景验证；后续整体验收不替代本票验证。实施过程中确定的字段、交互边界和验证结果记录在本票，不将静态原型细节自动升级为需求。不得迁移旧个人内容、增加学生笔记云端备份或扩大首版范围。
