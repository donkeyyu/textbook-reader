# 03: 增删节点和引用时连续更新布局

## Parent

[01：增量更新补充节点图](01-incremental-graph-updates.md)；[功能规格](../spec.md)。

**What to build:** 新建或删除个人节点、保存或删除引用时，以已有图为起点更新节点和连线并平稳收敛；拖动、悬停预览、隐藏恢复和教材阅读继续可用。

**Blocked by:** [02：改名和内容刷新时保持图与预览稳定](02-stable-content-updates.md)。该票建立属性与拓扑的更新分工及持久生命周期，03 在同一实现上延续，不另建并行引擎。

- [ ] 按稳定身份复用未删除节点的布局状态和图形，只增删变化节点；更新现有模拟，不重跑首次全图初始化。保留相机，允许真实拓扑变化后的连续运动。
- [ ] 两类连线保持原语义；重复引用、互引及最后一处引用删除正确，默认关联独立保留。只使用已保存快照，不把草稿变为边。
- [ ] 邻接、命中和悬停强调随变化更新。删除悬停或预览节点后清除失效对象；节点仍在时预览保持正确内容和位置，不依赖额外鼠标移动才纠正旧状态。
- [ ] 拖动中增删其他节点或连线不中断当前手势；删除当前拖动节点时释放捕获，不误触点击。隐藏或卸载时正常结束手势、清理帧请求及监听。
- [ ] 隐藏图时拓扑变化不启动布局和绘制；重开显示最新图并从保留状态继续。覆盖空图、孤立节点、删除最后一个节点和再次添加。
- [ ] 保留 08 的悬停恢复、Ctrl 预览与清理、抽屉平滑过渡及更新／resize 无黑帧行为；不重做其功能或退回旧实现。
- [ ] 从用户入口完整验证保存引用、反向查阅、节点选择、教材定位、关联返回、分屏、窄屏与草稿保护；确认反复更新无重复事件、失效图形积累或空闲布局活动。
- [ ] 复用引用投影测试与既有浏览器探针，通过受影响测试、类型检查和构建，记录数据规模、源码版本、前后观察和未验证范围。不新增公开测试接口或固定帧率承诺。

规格覆盖：US5–15、18–21，并回归 02 已交付行为。Worker、WASM、裁剪、局部图、存储改造继续排除。
