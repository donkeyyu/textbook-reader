# 17: macOS 本地完整路径集成验收

Status: ready-for-agent
Category: enhancement

**What to build:** 使用最终集成的 macOS 安装产物验证完整本地阅读与笔记路径，修复集成问题并记录证据；不等待缺失的 Windows 环境和生产下载源。

**Blocked by:** 07：自定义章节在同教材笔记间复用；09：笔记改名和移动后维护引用；10：将默认知识关联接入统一笔记；11：搜索与知识图统一指向本地笔记；15：macOS 原生对话框与安装启动验收

## Acceptance criteria

- [ ] 记录 macOS 版本、最终集成提交、安装产物摘要与运行位置；用安装产物而非开发服务器验证。
- [ ] 完成选库、手动文件、新建、自动保存、快捷键、三模式、属性、框选、自定义目录、关闭重开与双库状态隔离的连续用户路径。
- [ ] 通过真实本机 HTTP 首次下载并校验教材与初始包，断网重启后验证原页、字体、公式、统一笔记编辑、路径关联、原文跳转、名称/正文/tags 搜索和图谱。
- [ ] 覆盖正文与用户属性链接导航、改名/移动维护及部分失败；确认重建索引不删除笔记、目录或教材资源。
- [ ] 核对下载失败与重试、重复导入、无效 YAML、较新格式只读、重复 ID、磁盘拒写、外部冲突等已有证据；最终集成影响到的行为必须重验，未受影响检查可复用明确提交的证据。
- [ ] 核对本地编辑不改 AI 初始内容，来源的云端证据如实记录；没有学生内容上传、旧个人内容自动迁移、同步恢复或其他未授权功能。旧网页阅读路径仍可用。
- [ ] 记录通过项、失败修复、证据和未验证项；生产源由 16、Windows 由 13 承接。本票通过仅表示本地 macOS 集成通过，不表示首版发布完成。
