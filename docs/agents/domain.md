# Domain Docs

采用 single-context 布局：

- 根目录 `GLOSSARY.md`：项目领域术语。
- `docs/adr/`：架构决策记录。

## 读取规则

- 探索领域概念前，读取已有的 `GLOSSARY.md`。
- 涉及架构决策时，读取 `docs/adr/` 中相关的 ADR。
- 文件尚不存在时，直接继续；在术语或决策确定后，
  由 `domain-modeling` 按需创建。

## 使用规则

- 领域概念使用词汇表中的术语。
- 遇到词汇表未覆盖的概念，核对项目用语；
  确有缺口时，记录为后续领域建模事项。
- 建议与现有 ADR 冲突时，明确指出对应 ADR 和重议理由。
