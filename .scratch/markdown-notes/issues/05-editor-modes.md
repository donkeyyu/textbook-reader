# 05: 正文三模式与文件头独立切换

Status: ready-for-agent
Category: enhancement

**What to build:** 同一篇本地 Markdown 支持编辑、只读预览和实时预览，在编辑与实时预览模式下独立选择文件头源码或可编辑属性预览；只读预览中属性和位置仍可查看。

**Blocked by:** 02：外部编辑与自动保存冲突保护

## Acceptance criteria

- [x] 默认实时预览与属性预览；编辑与实时预览下文件头两种展示独立切换，修改同一份数据，切换保留草稿和可继续编辑的现场。
- [x] 编辑显示 Markdown 源码，只读预览的正文、文件头属性和 anchors 均不提供修改控件，但仍显示属性与位置，实时预览可在渲染中编辑；正文为单一连续纸面，不拆成解读与个人笔记两套输入。
- [x] 文件头支持新增、修改和删除用户属性；同库同名属性共用显示类型，类型不匹配提示但不强制转换文件值。顶层用户属性与 `_textbook` 隔离，同名不覆盖，只有内置 anchors 参与定位；同层重复键提示并保留源码草稿，修复前暂停保存与可视化写入。
- [x] 内置对象在属性预览中隐藏，笔记信息可只读查看 ID 和时间；源码默认折叠 `_textbook`，可展开查看完整内置对象，未知属性、注释与顺序尽量保留。
- [x] YAML 无效时显示错误位置、保留源码草稿、暂停自动保存和可视化写入；修复后可继续；不要求按原样保存无效 YAML。
- [x] 实现前固定理解、提示、注意、个人补充的 callout 标识及内容转换规则；支持折叠，未知类型仍保留标题和正文。
- [x] 公式、列表、链接及 callout 可正确渲染，HTML 不执行；公式与必要字体资源可离线使用，具体目标导航由 08 和 10 承接。
- [x] 模式偏好按库保存；重新打开后保留选择，不影响其他库的内容或本机窗口状态。

### 2026-11-01 实施前接口决定（供 04 复用）

- 理解：`> [!explanation] 标题`；提示：`> [!hint] 标题`；注意：`> [!warning] 标题`；个人补充：`> [!personal] 标题`。连续引用行构成正文。`[!type]-` 默认收起，`[!type]+` 默认展开，无符号为普通展开块。未知类型仍显示其类型、标题和正文，折叠规则相同。
- 初始解读转换：`title` 作为文件名；`preview` 不重复写入正文；`paragraphs` 按原序作为 explanation“理解”内容；`questionGuide.knowledgePoints` 仍有独立内容时放 explanation“相关知识”；`questionGuide.method` 放 hint 默认收起；`questionGuide.cautions` 放 warning；没有内容不造空块。个人新写部分可用 personal，但不迁移旧个人内容。`related` 由 10 接入链接，不在本票猜测路径。现有 HTML/SVG 图示不执行，04 需明确保留为静态安全资源或记录限制，不把 HTML 原样执行。
- 文件头与正文始终为同一 source；CodeMirror 实例在模式切换时保持，实时预览采用可点击渲染块与当前编辑块原位切换。属性类型及模式配置放 `.textbook/settings.json`，属性值仍只在笔记。
