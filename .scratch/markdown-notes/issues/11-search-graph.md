# 11: 搜索与知识图统一指向本地笔记

Status: ready-for-agent
Category: enhancement

**What to build:** 笔记列表、搜索和知识图使用同一份本地笔记数据，用户可从任一入口打开并继续编辑。

**Blocked by:** 04：导入 AI 初始内容，直接编辑统一笔记；08：路径链接、重名选择与反向引用

## Acceptance criteria

- [ ] 一篇 Markdown 对应一个节点，多 anchors 或跨教材归属不重复制造节点；缺少 ID 的手动文件可展示，不因投影写入 ID。
- [ ] 搜索覆盖笔记名称、可搜索正文和顶层 tags 标签；标签修改后更新检索结果，不增加聚类功能。笔记列表、搜索结果、教材相关入口和图谱打开相同本地内容。
- [ ] 图谱边与反向引用基于解析后的笔记链接；只有教材位置的关联不生成空节点。
- [ ] 保存、外部新增或修改、删除后更新搜索与图谱；未保存草稿不伪装为已持久化内容，旧异步结果不复活被删除节点。
- [ ] 重名候选展示教材上下文或摘要，缺失和歧义引用不形成错误连线；重复 ID 有可辨错误状态。
- [ ] 选择、关闭、切换视图和返回沿用草稿保护并保留图视野，不因索引变化无故重置阅读位置。
- [ ] 清理内存索引并重建可恢复相同内容投影；仅扫描不修改 Markdown。默认原文关系转换完成后由 12 联合验收。

本票需完成对应完整用户路径及有意义的失败场景验证；后续整体验收不替代本票验证。实施过程中确定的字段、交互边界和验证结果记录在本票，不将静态原型细节自动升级为需求。不得迁移旧个人内容、增加学生笔记云端备份或扩大首版范围。
