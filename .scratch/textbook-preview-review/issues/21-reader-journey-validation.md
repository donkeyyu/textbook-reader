# 21: 验证完整阅读路径与真实手机使用

**What to build:** 在同一版本验证找页、解读、方法、关联、返回和续读，交付产品线证据与必要修复。

**Blocked by:** [01：按课本印刷页码找到教材原页](01-printed-page-navigation.md)、[02：重新打开后继续上次阅读](02-resume-reading.md)、[03：按需展开方法并保留返回上下文](03-on-demand-method.md)

**External prerequisite:** 真实手机与操作条件；缺少时先完成其余检查，实机验证保持待完成。

**Spec:** [教材预习与复习规格](../spec.md) — Q1、Q3；回归A1–A4、B1–B4、C1–C3。

## Acceptance criteria

- [x] 在桌面与窄屏完成从纸书印刷页码开始的完整路径，覆盖首中末页、无结果、加载失败恢复、单条及合并入口、键盘与草稿保护。
- [x] 使用同一稳定版本检查刷新和重新打开后位置、跨尺寸恢复；同时检查关联返回的面板、方法展开、页内位置和焦点。
- [ ] 用真实手机检查普通正文、分数、几何图、入口点选和上下分区；记录设备、浏览器、版本、截图或操作记录与结果，不用视口仿真冒充实机。
- [x] 复现并修复本轮功能引入的问题，复测受影响路径。局部放大等超出规格的设计变更列为后续问题，不擅自扩展。
- [x] 交付产品线通过、失败、未验证清单；缺少实机时先完成其他检查并注明外部依赖，本任务和整体验收不记完成。
- [x] 运行最终受影响测试、类型检查与构建。避免重跑已经通过且未受影响的检查，不以扫描无命中代替用户路径证据。

## Boundaries

复用现有模块与检查，无需广泛预重构。只修改本票责任范围，保留并行工作和既有未提交改动。产品票包含必要实现与验证，内容票包含审核、修订与展示核验，观察票包含真实记录和问题复核。范围限教材解读，不增加诊断、作业辅导或课外培训。
