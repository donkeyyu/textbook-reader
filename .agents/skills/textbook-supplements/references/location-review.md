# 定位与关联审核

本参考用于新增、调整或审核阅读入口及其对应关系。教材来源与关联要求以项目 `docs/SPEC.md` 的 C1、C4、C5、R1 为准。

坐标建立与修正使用 [原文区域定位](../../index-pdf-content/references/location-regions.md)
及其叠框脚本。按 SPEC R8 区分整题范围与具体语句范围，文本检索命中只用于寻找候选位置。

## 原文与解读

沿真实入口同时查看原文框、标题、预览和正文，确认它们处理同一个理解问题。框应包含说明所需的完整语句、符号或图形，并避开无关的相邻对象。用原页全图判断上下文，用局部放大检查截字、分数和边界。

框住的那一行要回答的是同一句引出的问题；锚点选在哪里、什么内容挂在算式行、什么内容挂在结论句，见 skill 的“锚点与问题对齐”。位置对而内容答了别处的问题，改内容或移锚点，不靠调坐标补。

## 框的边界

- 按行首实测 `region.x`：接排行与缩进行的左界不同（同一段可以是 0.133 与 0.178 之差，屏幕上约 30 px），沿用上一行会让框切掉行首几个字。
- 按墨迹给 `height`：含 ½、上下标的行约 0.034，纯文字行 0.025；框上沿盖住分数是定位偏差，不是框体样式问题。
- 核对时把 `region` 换算到页面像素，与墨迹边界逐条比对：左界差 ≤3‰、右界略过句末即可。只看缩略图容易漏掉一个字的偏移。
- 判断“框整体偏移”是坐标还是渲染：先量框矩形的左、上、宽、高是否等于 `region` 的换算值；相等就说明框体没有 padding 或偏移，问题在坐标。

同一个理解问题的说明集中在对应原句或旁问入口，必要解释直接可读；用于对照的原句通过关联查阅。检查解释是否被分散到某个局部数据旁，或仍需打开另一条说明才能读懂。

独立情境或图表分别定位，不用一个大框代替不同对象。确实共用原文的说明可重叠，记录共用理由；入口在屏幕上的碰撞合并与内容的原文范围是两件事，不能为分开图标而改错来源区域。涉及跨页题时仍需核对完整上下文。

## 关联是否提供依据

带着来源处的具体问题打开目标，检查目标可见的原文或补充能否直接提供所需定义、判据或理由；仅有相关标题、知识名称或指向“另一条说明的说明”不算核对完成。选择足以支持当前理解的目标，说明如何使用它；目标可以只有教材原文，不要求再造一条解读。

目标范围应覆盖本题实际用到的条件和情形，关联名称与用途说明应区分定义、规则和用例。例如，本题涉及正数、负数和0的绝对值时，求法关联应包含三种情形。

区分当前已用的依据与后续将学的联系。原文未提供所需前置知识时，按 C2 补足必要说明，并保留来源核对状态，不拼凑精确页码。

## 展示与记录

按本次改动范围和支持的视口，分别检查默认正文与方法展开后的内容：必要解释能否直接读到，展开内容是否增加有效提示，原文高亮是否可辨认。实际跳转后核对目标的可见内容，再返回检查来源条目、阅读位置、方法状态和焦点；浏览器检查复用项目 `README.md` 的“浏览器回归”入口。

记录具体条目、修订理由、核对材料及未验证部分。结构校验、原页视觉核对和实际点击往返分别记录，链接存在不能代替语义审核。
