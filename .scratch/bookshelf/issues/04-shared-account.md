# 04: 书架与阅读页共用账号及个人内容

**Parent:** [书架、教材管理与启动恢复规格](../spec.md)

**What to build:** 读者从书架或阅读页登录同一账号，登录后留在原页面，并使用已有个人内容同步能力。页面切换、退出或账号变化不丢失受保护的草稿，也不串用其他账号的内容。

**Blocked by:** [01：首次进入书架、添加教材并开始阅读](01-shelf-and-reading.md)。

- [x] 书架与阅读页均提供登录／账号入口，复用既有邮箱登录窗口和会话，不建立第二套认证状态或新增登录方式。
- [x] 未登录仍可管理本地书架和阅读默认内容；账号内容载入后再开放对应个人编辑行为。
- [x] 从书架登录成功后留在书架；从阅读页登录成功后保留教材版本与原页位置。登录窗口关闭后归还焦点。
- [x] 在两个页面之间切换保持账号状态一致；载入并同步正确账号的笔记和个人补充，退出或账号切换后，旧账号内容不得作为新账号内容展示或保存，也不得覆盖或混入新账号的个人内容。
- [x] 发送邮件、登录、退出和个人内容加载分别提供必要等待与失败反馈，可重试；失败时仍可阅读默认内容，不伪报保存成功。
- [x] 返回书架、主动退出及改变编辑上下文的动作沿用草稿保护；取消操作保留原页面和编辑内容，普通开合登录窗口不要求放弃草稿。外部会话变化导致账号切换或退出时，旧草稿保留为带归属提示的待处理内容，供复制或明确放弃；旧请求返回或草稿重试不得写入新账号，也不得将旧保存结果显示为新账号保存成功。
- [x] 登录、退出及空云端状态不覆盖本地书架成员和阅读记录；不把书架或启动目的地加入云端同步范围。
- [x] 桌面与手机均能操作账号窗口，背景不可交互或滚动，支持 Escape 关闭、可见焦点和焦点归还。
- [x] 用专用测试账号和隔离环境完成未登录阅读 → 登录 → 个人内容载入／保存 → 页面切换 → 退出，并验证失败重试、账号隔离与草稿保护；复用既有测试入口，不修改真实用户内容。覆盖旧账号保存响应延迟 → 外部账号变化 → 响应返回后旧草稿及归属提示仍在 → 重试不写入新账号且不伪报新账号保存成功。
- [x] 不新增数据库表、同步 API 或后端教材管理服务作为前提；若既有能力存在无法复用的实际缺口，记录证据和范围影响，不自行扩展需求。
- [x] 更新账号入口及实际交互说明，运行受影响的既有检查并记录结果。
