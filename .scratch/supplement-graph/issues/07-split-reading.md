# 07: 图与教材分屏定位并保留阅读现场

**Blocked by:** 03：从教材补充进入可探索的完整图。

**What to build:** 用户从图中的解读定位教材时，桌面默认分屏并标出原文；可调整宽度、隐藏关闭或重新打开任一视图。窄屏切换图与教材，各自位置不丢。

- [x] 点击节点只切换解读；点击定位才打开分屏并滚动原文。只有原文的关联也可定位，失败保留来源并可重试。
- [x] 教材自由滚动不移动图；分屏调整和窗口变化保持页内位置与图视野。
- [x] 关闭、隐藏和重开保留会话上下文及草稿；两视图关闭后仍有恢复入口。
- [x] 窄屏可切换视图，键盘可调分隔条并操作关闭与返回；焦点有有效落点。
- [x] 原有关联返回、分组条目和方法开合继续有效；刷新延续现有教材续读，不新增图布局持久化。
- [x] 浏览器完成跨章定位、调整宽度、关闭重开、窄屏切换和失败路径；06 完成后补走已确认的“教材 → 图 → 笔记链接 → 分屏定位 → 刷新恢复”整条路径，此补验不阻塞本票的独立实现。

规格覆盖：US9–14、35、37；T11–14。可与 04–06 并行；整条路径由最后完成的相关任务交付时补验，不另设纯测试任务。
