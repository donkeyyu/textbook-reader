## 实现

- 题目引导的“思路与方法”使用原生 button，提供 `aria-expanded` 与 `aria-controls`，初次打开和直接重开均收起。复用原始方法数据，不创建内容副本。
- 方法内容仅隐藏对应方法段落；考查知识点、注意事项、相关知识、原有必要说明与教材原页仍可读。概念、推导说明不使用方法开合控件。
- 方法状态保存在阅读器会话内；密集入口切换或直接重开时重新收起。关联来源上下文同时记录状态，返回时与来源解读、页内区域、面板滚动和来源链接焦点一起恢复；关闭与刷新不延续方法状态。
- 方法开合仅改变方法状态，保留笔记编辑器；全局脏稿拦截只对该控件放行。关闭、跳页、切题等原有保护继续生效。
