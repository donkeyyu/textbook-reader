# 教材索引

用于教材结构梳理、印刷页码映射和段落、例题、习题的定位。
本项目的内容依据遵循 `docs/SPEC.md` 的 C1、C4；材料入口见 `docs/CONTEXT.md`。
在其他项目复用时，读取调用方的教材来源和定位要求。

## 来源与页码

- 将索引的 PDF SHA-256 与教材来源记录对应。出版社、册次、课程标准年份、
  审定年份、出版年份和印次分别记录；原页未给出的信息保留为未核实。
  有已核对的来源记录时复用它，不要求每批页面重复建立版本记录。
- `physical_page` 始终为从 1 开始的 PDF 页序。
  `printed_page` 只填写该页实际可见并已核对的印刷页码，保留其原样字符串。
  页面没有印刷页码时标为 `absent`；看不清或未核对时标为 `unverified`。
  目录中写出的目标页码可作查找线索，目标页核实后才建立映射。
- 每页单独核对，不通过固定偏移推定其他页面。封面、插页、前言和目录也按
  PDF 页序记录；不把未印页码的页面自动编号为正文页。

## 内容定位

根据当前任务选取定位粒度。全书导航可先做到章节和小节，
编写具体解读时再细化到段落、例题、习题或步骤；不自动承诺逐段全覆盖。

`anchors.kind` 可使用 `section`、`paragraph`、`definition`、`property`、
`example`、`exercise`、`step`、`figure`、`table`。
这些是建议标签，按教材结构使用，无需每页凑齐。

- `label` 保留原页标题、题号或符号。无显式标签时，用原文短语加位置描述。
- `locator` 写清页内位置和上下文，如“小节标题下第一段”或“例题解答中部”。
  自拟定位语属于导航元数据，不冒充教材原句。
- 跨页例题和习题分别建立页内定位，在 `locator` 中注明已核对的相邻 PDF 页序。
  编写内容前查看跨页上下文，不能把续页当成独立题目。
- 知识联系和解题理由属于后续解读。索引只提供可核实的出处；
  待核实的关联目标保留为缺口，不生成精确跳转链接。

需要界面坐标时，另行记录坐标系、页图尺寸和所绑定的图片哈希。
通用索引不预设坐标系；本项目的原文框选使用
[区域定位流程](location-regions.md)及现有 location JSON，避免把文本命中框直接用作内容框。

## 本项目的保留方式

教材 PDF 的来源记录使用同名 `.source.json`。原始 PDF 保持本地保存。
可将索引和 manifest 放在 `materials/indexes/<教材标识>/`；这是本技能的建议位置，
并非已确认的产品存储方案。批量页图和提取文本默认留在本地准备目录，
需要长期保留时先按项目约定设置忽略规则，避免混入版本控制。
