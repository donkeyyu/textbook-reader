# 桌面笔记库

桌面端复用 React/Vite 和 CodeMirror，提供本地笔记库、编辑、只读预览与实时预览。网页入口继续使用原阅读器。票 02 提供自动保存、外部变化与冲突恢复；票 05 在同一 source 上接入正文与文件头的独立展示。

```sh
npm ci
npm run desktop                 # 先构建，再启动 Electron；不连接开发服务器
npm run test:desktop            # 文件、格式、时间与本机状态检查
npm run desktop:check           # 编译后应用的保存/冲突回归；选库对话框使用桩
node desktop/check-modes.mjs    # 编译后应用的模式、属性、公式及设置回归
npm run desktop:pack:mac        # Intel macOS DMG
npm run desktop:pack:win        # Windows x64 NSIS 安装包
```

固定版本为 Electron 45.2.1、electron-builder 26.18.0。若本机 npm 策略未执行 Electron 下载脚本，可执行 `node node_modules/electron/install.js`；不需修改系统安全设置。产物在 `release/`，不纳入 Git。首版使用默认图标，未签名、公证或发布，发布工作归票 12。当前 macOS 构建目标为 x64；Windows 实机验证归票 13。

`DESKTOP_EXECUTABLE=/完整路径/课本解读.app/Contents/MacOS/课本解读 npm run desktop:check` 可对从 DMG 复制安装后的程序运行同一检查。检查创建独立临时库与应用数据目录，保留路径并打印结果；不读取用户笔记，不调用云端个人内容接口。原生选库窗口另用真实系统对话框验证，不能以该桩代替。

## 文件与接口

用户选择的目录是库根目录。文件名（含可选子目录）就是笔记名称；新建时父目录须已存在。同名建议采用“名称（2）.md”；新建通过独占链接提交；现有文件先保留同目录的磁盘原件，再独占安装已同步的候选文件。支持 UTF-8 `.md`，单篇上限 10 MB。读取和扫描不写文件；隐藏文件、库内符号链接、目录联接及硬链接不参与笔记操作。

主进程持有库路径，渲染端仅持有本轮选库 token 与相对路径。preload 暴露选库、列表、读取、保存、本机状态与草稿保护，以及具名的 `copy`、`protectDraft`、`recoveries` 和 `onChange`；主进程校验主窗口、主框架、应用 URL、参数及每段库内路径。启用沙箱、上下文隔离和 CSP，禁用 Node 集成、外部导航、弹窗及权限请求。源码编辑器将 HTML 当文本；预览跳过 HTML，远程图片不发起请求。普通链接只读显示，目标导航由票 08 接入。

`save(token, path, source, revision)` 中 `revision` 为读取内容的 SHA-256；新建为 `null`。主进程串行写入，写前重新核对摘要与当前用户的文件写权限。每次写入先同步临时文件，将磁盘原文及候选内容写入库外 `save-recovery/<库摘要>/<操作UUID>.json`。现有文件移到同目录的隐藏 `.textbook-save-….tmp.previous`，再检查实际被移出的内容；候选文件通过独占链接安装，不覆盖此间被外部程序新建的目标。安装后检查目标与原件，正常完成才清理记录和隐藏原件。

失败时仅在目标为空时回放原件；原件已持久记录或已安全回放后才清理隐藏副本。恢复存储也失败时保留该副本。进程被强制终止可能留下隐藏原件及未完成记录；“恢复记录”会读取原文、候选和实际被移出的外部版本，分别打开为待核对草稿。恢复草稿首次保存使用新身份，不覆盖原笔记；无效 YAML 保留原文，修复后才保存。扫描和枚举恢复记录不写 Markdown。记录是辅助副本，不能冒充一次已成功保存。

上述步骤不是跨外部编辑器的事务或原子比较交换。检查后继续持有旧句柄的写入、后续再次修改及系统掉电仍受文件系统行为约束；不宣称消除全部竞态。自动检查覆盖写前、最终检查后、安装间隙、写后变化，以及真正 SIGKILL 后重开并读取尚未写入记录的实际外部版本。

YAML 使用文档 AST 修改内置字段，保留未知属性、注释及顺序；当前 `_textbook.schema_version` 为 1，新笔记使用 UUID。时间仅在候选内容成功写入后反馈为已保存。手动文件不补创建时间，仅补 ID 不生成时间；正文、用户属性及 anchors 修改才推进合法更新时间。异常时间保留并提示；异常 ID、重复字段、无效 YAML 阻止保存，允许用户明确修改源码后重试。较新格式只读，键盘命令及撤销也受 CodeMirror 的只读状态约束。

## 本机状态

Electron `userData` 中的 `last-vault.json` 保存上次库路径；`vaults/<库路径摘要>.json` 保存各库的窗口位置和大小、当前文件、光标及滚动位置。本机状态不放进笔记库，也不把编辑草稿当作已保存正文；显式草稿保护及写入失败的恢复副本按上文处理。可用位置在重开时恢复；超出文件或显示器范围时限制到可用范围，损坏状态提示后仍可选择并阅读文件。窗口关闭和切换文件或库时保护草稿，取消继续保留当前内容。

有效修改在停止输入 650 ms 后自动保存，按钮及 Ctrl/Cmd+S 可立即保存。保存期间编辑器仍可输入；后续输入保留，并携带本次生成的身份与时间继续保存。无效 YAML 暂停自动保存并显示位置；失败后暂停重试，继续修改、点击保存或另存均可保留草稿。

主进程使用递归文件监听，80 ms 合并通知；1200 ms 扫描兜底，内存索引重新读取文件戳改变或此前读取失败的内容。监听只更新列表、摘要、身份冲突及文件修改时间，不维护 Markdown 时间。无草稿时重读；有草稿时暂停保存，显示差异、另存及采用磁盘版本。采用前必须先成功写入草稿保护记录，取消不改变现场。重复 ID 显示所有相关路径，用户明确选择“将此副本设为新笔记”；应用内复制也生成新 UUID 和新建时间，保留 AI 来源及未知属性。文件修改时间独立展示。

旧库的延迟状态响应只影响同一 token 的界面；切库后拒绝的旧状态请求不会污染新库错误提示，当前库的真实失败仍提示。恢复权限后可重试。自动交互检查使用当前平台真实 Electron 进程与文件系统，但对原生选择框和关闭确认采用可控返回值，须与真实原生窗口证据分别记录。

## 教材下载与离线阅读（票 03）

在“笔记库”选择文件夹后，从“教材书架”明确添加当前版本。添加完成前不写书架成员；下载失败可重试，已校验文件会复用。教材页图、缩略图和目录共 405 项，使用票 14 的固定清单及代码内固定 SHA-256。完成后仍使用原有连续阅读器、目录、页面缩略图、搜索、原文定位与知识图。当前内置解读只读提供；04 将接入初始 Markdown 笔记包，本票不生成 Markdown 或读取云端个人内容。

资源字节保存在 Electron `userData/textbook-resources/<教材版本ID>/`，属于持久资料，不放在索引或 Chromium 缓存中。`complete.json` 只在全量资源及安装资源校验通过后写入；启动时重新逐项校验，不凭该标记宣告完成。每次读取原页也校验对应字节，发现丢失或损坏后撤销当前可用状态并提供重试。下载先核对 HTTP 状态、长度和 SHA-256，再写同目录临时文件、同步并原子提交。

教材目录仅在明确添加动作中写入所选库的 `.textbook/textbooks/<教材版本ID>/catalog.json`。相同目录复用，已有不同内容则保留并报错，不覆盖 `custom.json` 或笔记。所有中间目录拒绝符号链接和目录联接，目录文件拒绝符号链接、硬链接及非普通文件。下载过程中切库会让旧 token 失效，提交目录前重新检查，目录提交与切库使用同一串行队列；已下载的资源仍可供另一库明确添加时复用。

书架成员、启动目的地与阅读位置使用 `desktop-textbooks:<库路径摘要>:` 命名空间保存到桌面 origin 的本机存储；与网页版键及其他笔记库隔离。移出、撤销、重加均保留资源、目录、个人文件及该库续读记录。`window.textbookResources` 只提供 `context`、`status`、`add(vaultToken, textbookId)` 和 `catalog(vaultToken)`；主进程校验调用来源、当前库 token 和固定教材版本。返回的添加结果含 `textbookId`、`catalogPath` 和 `manifestSha256`，供 04 在同一明确添加动作中衔接导入。

生产来源尚未提供，默认添加会提示缺少下载源。发行配置可向主进程提供 `TEXTBOOK_DOWNLOAD_BASE_URL`，须为获准的 HTTPS 目录 URL，以 `/` 结尾且无凭据、查询或片段；不跟随重定向，不向渲染端暴露该配置。清单摘要固定在可信应用代码中，不能由下载服务器替换。不要将 token 或个人凭据放入客户端。生产来源与发布授权由后续票承接。

`desktop:build` 会先构建前端，再移除 `dist/textbooks/` 并生成构建专属的安装资源清单；打包规则同时排除该目录。字体、公式 JS 及所有延迟加载 chunk 留在安装包，并在启动时核对。桌面入口另加载 Pixi 的静态 shader/uniform 适配模块，以遵守禁止 eval 的 CSP；网页入口不加载该适配模块。普通 `npm run build` 仍产生包含教材的网页版构建。

```sh
# 只供本机验收，服务传输真实 HTTP；不表示教材已公开发布。
DESKTOP_EXECUTABLE=/完整路径/课本解读.app/Contents/MacOS/课本解读 node desktop/check-textbooks.mjs
```

该检查启动临时 loopback HTTP 服务，以安装产物执行失败重试、慢下载时切库、双库明确添加和各自续读。随后停止服务、移除来源配置、清理该临时应用的 Chromium 缓存，并以 Electron 断网模拟重启，逐项检查 405 个资源的字节摘要和图片解码、6 个字体、202 个原页节点、目录、缩略图、公式、搜索定位、知识图与移出重加。`--textbook-local-http` 只在显式验收时允许 loopback HTTP。它使用对话框桩，macOS 原生安装和窗口操作仍归 15；Windows 实机归 13。

## 正文与属性（票 05）

默认“实时预览 + 属性预览”。编辑模式展示 Markdown 源码；实时预览在同一 CodeMirror 中渲染未编辑的块，点击或用键盘进入块后原位编辑；只读预览不提供正文、属性、位置或文件写入控件。切换保留同一编辑器及其文档、光标和撤销历史。保存回写只派发实际差异，不用整篇替换破坏正文的撤销范围。

文件头在可编辑模式下独立选择“源码／属性预览”。源码用 YAML AST 范围默认折叠 `_textbook`，可展开；属性预览隐藏保留对象，笔记信息可查看 ID 与时间，顶部笔记位置只读显示已有 anchors。票 06 接入位置编辑。顶层用户字段独立增删改，普通列表支持逐项操作；嵌套对象和复杂 YAML 保留，转到源码编辑。无效 YAML、同层重复键或别名损坏提示位置、保留源码，并暂停保存和属性写入。

callout 为 `explanation`（理解）、`hint`（提示）、`warning`（注意）、`personal`（个人补充）；`[!type]-` 默认折叠，`[!type]+` 默认展开，无符号为普通展开块。未知类型保留标题、类型与正文。公式使用已有本地 MathJax SVG 流程；代码块、行内代码与转义美元保持字面量，不与块外公式配对。必要字体和公式 chunk 已包括在安装资源中。

模式与同库同名属性的显示类型保存于 `.textbook/settings.json`。首次读取尚未登记的属性时，以其值推断并登记显示类型；后续不符只提示，不改文件值。设置只保存模式及类型，不存笔记属性值；未知配置字段保留。版本摘要阻止覆盖外部修改，配置读取失败时仍能编辑笔记，并提供重新读取配置。设置路径拒绝符号链接、硬链接与目录联接；失败保留原件，中断后缺少目标且有隐藏原件时暂停写入，待核对恢复。
