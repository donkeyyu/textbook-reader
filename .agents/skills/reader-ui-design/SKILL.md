# 阅读界面设计取舍

把空间和注意力留给教材、解读与知识联系。行为要求查 [SPEC](../../../docs/SPEC.md)，组件与视觉约定查 [DESIGN](../../../DESIGN.md)；以下准则用于新场景的取舍，不另立组件规格。

## 六项准则

- **先减外壳，再调密度。** 优先删除重复入口、空占位和次要信息常驻行，再缩减工具栏与面板。省下的空间交给内容，保留正文可读性、操作触区和焦点；长标题换行比压小正文更合适。
- **按对象分配空间。** 全局放跨视图操作，面板导航随面板显示，条目操作靠近条目。解读与预览只占所属区域，响应式布局依据容器可用宽度；页面级模态另按页面处理。
- **次要内容按需出现。** 统计、图例和低频设置可折叠，重复预览可省去。开关展开前后留在同一位置，展开层受可用空间约束；错误、草稿和恢复入口仍须可见。
- **图标省空间，文字说明内容。** 可识别操作用具名图标，标题与需要解释的动作保留文字。边框按层级取舍：嵌入式控件可平面呈现，画布悬浮控件需明确边界；不统一去框或缩小所有元素。
- **选择后少移动。** 自动完成相关视图中必要的定位，省去重复点击；目标已可见时保持视野，不可见时只做必要平移。保留目录展开与筛选，显式定位操作才重置视野。悬停预览、选择与拖动保持不同含义。
- **保持阅读连续。** 解读展开后保留原文焦点，用类型色与局部强调表达联系。开合、调宽和更新保留阅读与编辑现场；同条续读、新入口和关联返回按各自状态语义恢复。动效应呈现变化，不能掩盖闪黑或状态重置。

## 核对

用真实长内容和分屏窄容器走通受影响的阅读往返，检查节省空间后是否仍能辨认、操作和返回。按 [README](../../../README.md#选择回归入口) 选择桌面或网页检查。

需要追溯偏好或判断旧方案是否仍有效时，读 [会话依据](references/session-evidence.md)。
