# 12: 双平台首版交付与完整离线路径验收

Status: ready-for-agent
Category: enhancement

**What to build:** 用 macOS、Windows 安装产物验证首版完整阅读和编辑流程，交付明确可运行范围及限制。

**Blocked by:** 07：自定义章节在同教材笔记间复用；09：笔记改名和移动后维护引用；10：将默认知识关联接入统一笔记；11：搜索与知识图统一指向本地笔记

## Acceptance criteria

- [ ] 确定并记录支持的两平台系统版本；沿用 01 的打包能力并确定正式安装包构建和分发方式；对外发布前完成相应签名安排，不以开发服务器启动代替安装产物验证。
- [ ] 两平台验证选库、手动文件、新建、自动保存、快捷键、模式切换、属性、框选、自定义目录及关闭重开；核对按库恢复上次笔记库、窗口、光标与滚动位置，以及位置失效时仍可打开内容。
- [ ] 真实首次下载并校验教材与初始包；断网重启后验证原页、字体、公式、笔记编辑、路径关联、原文跳转、名称、正文与 tags 检索及图谱；覆盖正文和用户属性内链接的导航与改名维护。
- [ ] 验证下载中断及损坏、重复导入、无效 YAML、较新格式只读、重复 ID、磁盘拒写、外部冲突与部分引用改写失败，保留可核对证据。
- [ ] 验证来源引用能核对到云端独立 AI 初始版本，本地编辑不覆盖它；没有学生笔记上传、旧个人内容自动迁移或同步恢复入口。
- [ ] 验证目录边界、外部链接或路径输入不能越权；清理索引不删除持久资料与离线教材。
- [ ] 旧网页版仍保持原有路径，旧个人内容不被修改；桌面仅有已确认首版范围，不混入 Git、插件、多窗口、聚类或通用批量功能。
- [ ] 交付已验证项、未验证项和已知限制；未完成必需平台验证或真实下载验证时不得标为首版完成，不将运行成功表述为学习效果证据。

## Scope and verification

依据：项目规格 R15（2026-11-01 已确认方案）。实现前阅读当前规格、适用项目约定与技能。实施授权与调度见[任务索引](../spec.md#实施调度2026-11-01)；执行时仅领取依赖已完成的任务。

本票需完成对应完整用户路径及有意义的失败场景验证；后续整体验收不替代本票验证。实施过程中确定的字段、交互边界和验证结果记录在本票，不将静态原型细节自动升级为需求。不得迁移旧个人内容、增加学生笔记云端备份或扩大首版范围。
