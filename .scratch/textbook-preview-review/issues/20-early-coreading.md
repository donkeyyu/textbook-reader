# 20: 用首批样本开展早期独读与共读观察

**What to build:** 在首批核对样本就绪后即取得学生预习、复述和家长共读反馈，不等待全部功能与全书审核。

**Blocked by:** [04的已审核样本交付](04-chapter-1-pages-8-20.md)（仅等待样本及审核记录就绪，不等待04整票完成）

**External prerequisite:** DonQ 协调真人参与者与时间；agent可协助材料和记录，不能冒充真人或自行联系他人。

**Spec:** [教材预习与复习规格](../spec.md) — D2、D3的早期证据；用户故事24–25、28–31。

## Acceptance criteria

- [ ] 由DonQ协调参与者与时间；人员准备可立即进行；核对04的样本交付记录后即可开展观察，不必等该票47项审核全部完成，未经核对材料不能作为本票完成证据。
- [ ] 使用首批已审核样本和当时可用阅读器，至少记录学生首次阅读后关闭说明的复述或辨认，以及家长围绕含义或理由的共读；说明学生先备知识、家长数学背景与未覆盖情况。
- [ ] 记录读前理解、查阅过程、实际回答、提示及困难，标明教材与应用版本；区分界面、内容和先备知识障碍，不用模拟角色替代真人。
- [ ] 汇总样本问题，在范围内修订并复核受影响样本；记录无帮助或增加干扰的结果，不为取得正面结论引导回答。
- [ ] 交付可用于后续新版复核的观察记录和问题清单。早期观察不验证尚未实现的页码、续读或方法折叠，不代表D2全部完成。
- [ ] 实际参与者不可用时保持未完成；可以继续准备记录材料，不主动联系他人，不编造人数或回答。

## Boundaries

复用现有模块与检查，无需广泛预重构。只修改本票责任范围，保留并行工作和既有未提交改动。产品票包含必要实现与验证，内容票包含审核、修订与展示核验，观察票包含真实记录和问题复核。范围限教材解读，不增加诊断、作业辅导或课外培训。
