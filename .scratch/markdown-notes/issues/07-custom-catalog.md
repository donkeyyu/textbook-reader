# 07: 自定义章节在同教材笔记间复用

Status: ready-for-agent
Category: enhancement

**What to build:** 用户创建或修改教材的自定义章、节，其他笔记可复用，并在条目删除和原目录更新时保留可修复的引用。

**Blocked by:** 06：顶部笔记位置与教材框选往返

## Acceptance criteria

- [x] 下拉区分教材索引条目与自定义条目；新增章、节具有稳定标识和正确父级，同教材其他笔记无需重复创建即可选择。
- [x] 自定义数据保存到教材级持久文件，与原始索引分开，重新打开后可读取；配置或索引缓存清理不删除自定义条目。
- [x] 同父级同名提示复用，改名保持 ID 并反映到引用处；不同教材互不混淆，不隐含跨用户共享。
- [x] 删除被引用条目前显示引用数量，要求选择替代条目或明确移除归属，取消不改变笔记；失败不伪报全部完成。
- [x] 目录更新不按数组顺序重建标识；旧条目消失时保留失效引用和提示，不猜测新条目，不覆盖自定义条目。
- [x] 目录归属不代替原文位置；变更章、节不静默改动页面与区域，矛盾提示遵循 06。
- [x] 不提供通用批量更新或聚类界面；条目删除所需引用处理只覆盖该操作。

本票需完成对应完整用户路径及有意义的失败场景验证；后续整体验收不替代本票验证。实施过程中确定的字段、交互边界和验证结果记录在本票，不将静态原型细节自动升级为需求。不得迁移旧个人内容、增加学生笔记云端备份或扩大首版范围。
