# 08: 路径链接、重名选择与反向引用

Status: ready-for-agent
Category: enhancement

**What to build:** 用户通过双括号链接本地笔记，选择同名候选后得到明确路径，并可导航和查看反向引用。

**Blocked by:** 05：正文三模式与文件头独立切换

## Acceptance criteria

- [ ] 实施前固定库内路径的大小写、扩展名和转义约定，覆盖 macOS、Windows；路径不能越过笔记库。
- [ ] 唯一名称可解析，多个同名目标标为歧义，不按章节相近或旧绑定猜选；候选显示现有教材、章节、页码、区域预览或可用摘要，缺失信息不伪造。
- [ ] 选择同名候选写入明确库内路径并可保留显示别名；不额外保存旧式目标 ID 绑定作为链接依据。
- [ ] 缺失目标显示未找到，由用户选择修复或创建；创建按 UUID 与重名保护规则执行，不因扫描自动创建文件。
- [ ] 已解析链接可打开目标并返回来源编辑现场；正文和用户属性值中的合法笔记链接均参与解析与反向引用，反向引用从持久内容重建，重复引用、移除引用和未保存草稿处理一致。
- [ ] 代码、转义文本等非链接语法不产生错误引用；标题与块级链接保留原文且不伪报支持。
- [ ] 缺少 ID 的手动笔记也可通过路径访问和索引，解析不修改文件；路径被新文件复用且无历史证据时不声称识别原身份。
- [ ] 反向引用和搜索索引可重建，不删除笔记；无联网条件也能解析本地链接。
