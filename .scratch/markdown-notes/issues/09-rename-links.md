# 09: 笔记改名和移动后维护引用

Status: ready-for-agent
Category: enhancement

**What to build:** 用户改名或移动笔记时维护确定的引用；对外部改名和部分失败提供可修复结果。

**Blocked by:** 02：外部编辑与自动保存冲突保护；08：路径链接、重名选择与反向引用

## Acceptance criteria

- [x] 应用内改名、移动保持笔记 ID、创建时间及 AI 来源引用；仅路径变化不更新其内容时间，同目录目标存在时阻止覆盖。
- [x] 操作前列出可确定的引用，覆盖正文与用户属性值中的链接，保留显示别名及其他 YAML 数据；只改写确认指向原文件的链接，不修改同名但指向其他目标的内容。
- [x] 每个引用文件写入前检查外部变化，引用文本成功修改后维护该文件的更新时间。
- [x] 多文件操作部分失败时显示已完成与未完成结果并可重试，不宣称全部成功；记录可恢复机制并验证中断场景。
- [x] 外部改名、移动仅在唯一 ID 与旧索引证据一致时提示修复；扫描不自动改写文件。无历史证据时保留失效链接。
- [x] 重复 ID 或外部内容冲突不错误认领目标；有身份冲突证据时提示，不以名字相同绕过。
- [x] macOS 验证中文文件名、跨目录重名、拒绝覆盖及部分失败后重试；大小写行为遵守 08 的约定，Windows 实机验证由 13 承接。
