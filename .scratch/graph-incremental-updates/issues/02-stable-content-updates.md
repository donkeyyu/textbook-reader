# 02: 改名和内容刷新时保持图与预览稳定

## Parent

[01：增量更新补充节点图](01-incremental-graph-updates.md)；[功能规格](../spec.md)。

**What to build:** 保存节点标题、正文或显示属性后，图和 Ctrl 预览显示最新内容，节点位置、相机与当前操作连续；相同数据重新读取不会重排图。

**Blocked by:** [补充图谱 08：悬停聚焦、平滑解读抽屉与 Ctrl 预览](../../supplement-graph/issues/08-graph-hover-preview-motion.md)完成验收并交还共享图交互修改窗口。既有 01 是范围总任务，不是需先完成的阻塞票。

- [x] 分开显示属性和拓扑更新；仅改名、类型变化、无连线变化的正文修改不销毁全图、不额外启动布局。必要的生命周期整理随此路径交付，不独立建立通用引擎层。
- [x] 等值输入、节点或边顺序变化、引用次数变化但连线集合未变，不触发布局重排。已运动节点可继续冷却，不重置速度和拖动状态。
- [x] 标题、类型、搜索候选及 Ctrl 预览内容同步更新；同名节点不合并。悬停优先聚焦、离开恢复选择、预览上下位置及静止按松 Ctrl 行为保持正确。
- [x] 保留相机、解读草稿、教材位置与抽屉状态；属性更新不取消有效拖动，不触发选择或保存。
- [x] 隐藏时属性更新不运行布局或绘制；重开显示最新内容、保留视野，已冷却图不重新启动。
- [x] 通过现有图入口验证改名、正文更新、悬停预览、拖动、隐藏重开和抽屉／resize 无黑帧；记录前后观察，通过受影响测试、类型检查与构建。
- [x] DonQ 追加：在同一节点停留 100ms 后才聚焦；细微移动不重置计时，跨节点、离开、拖动、隐藏、失焦及卸载取消旧计时。属性更新保留有效计时与已聚焦状态；Ctrl 预览依赖已确认 hover，点击和键盘选择不等待该计时。

规格覆盖：US1–4、12–13、16–19、21。拓扑变化仍可沿用此前的可用路径，完整增量拓扑更新由 03 承接。
