# 01: 按课本印刷页码找到教材原页

> 后续变更（2026-10-25）：本票保留最初实现与验收记录。双页码显示和跳页模式已由 DonQ 后续确认的 [SPEC R7](../../../docs/SPEC.md#r7-本轮确认的页面设计) 替代。后续导航修改和复验按 R7 执行，不恢复本票旧界面；历史通过记录只说明当时版本。

**What to build:** 让学生和家长从纸书印刷页码找到同一原页，同时明确文件页序，保留完整教材访问。

**Blocked by:** None (can start immediately)

**Spec:** [教材预习与复习规格](../spec.md) — A1–A4；用户故事1–7、20。

## Acceptance criteria

- [x] 从已核对的全书映射建立运行时查找，覆盖无解读页面；无印刷页码保留为空，不按固定偏移推算，不以印刷页码替代教材位置标识。
- [x] 导航显示文件页序和课本印刷页码；无印刷页码时明确说明。默认按课本页码跳转，也能切换文件页序。
- [x] 印刷第3页定位到文件第10页；文件首、中、末页与无印刷页码页面均可访问；重复印刷标签不得静默取首项。
- [x] 空值、错误格式、不存在标签、越界输入保留当前位置，给出可修正的提示和模式切换。
- [x] 知识关联清楚标注目标页码种类；解读标题、正文不重复当前位置页码；导航展开、收起和窄屏均可操作。
- [x] 完成浏览器找页与错误恢复演示，覆盖键盘；复用目录测试补充映射边界，运行受影响测试、类型检查与构建。

## Boundaries

复用现有模块与检查，无需广泛预重构。只修改本票责任范围，保留并行工作和既有未提交改动。产品票包含必要实现与验证，内容票包含审核、修订与展示核验，观察票包含真实记录和问题复核。范围限教材解读，不增加诊断、作业辅导或课外培训。
