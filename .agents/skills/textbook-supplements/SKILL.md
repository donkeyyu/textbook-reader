# 教材补充理解素材

为学生当前正在阅读的教材内容补足理解依据。早期版本以必要、有价值、足以解决当前问题为取舍标准。

## 项目依据

以下路径均相对“课本解读”项目根目录，不相对本 skill 目录。

- 开始前读取 `docs/SPEC.md` 的需求层级、S1–S3 和 C1–C6，按其中的范围及验收条件工作。
- 分类含义以 `GLOSSARY.md` 为准；具体语句或步骤可兼具多种学习作用。
- 查找教材文件时，读取 `docs/CONTEXT.md` 的“参考材料”，并确认路径实际可用。

本 skill 维护选材与编写方法；项目目标、范围和验收要求仍由 SPEC.md 管理。

## 选材与编写

1. **核对原位置**：查看教材原页及相邻上下文，确认版本、印刷页码、段落、题号或步骤。文本提取用于检索，公式和排版以原页核对。原页缺失时，可整理候选补充点，并标明待核实的来源；精确位置及教材对应关系仅在核实后采用。
2. **确定理解缺口**：说明原位置尚未讲清什么，以及补充后预期支持哪个具体学习动作。一般段落按 C2 取舍，原文及上下文已足够时可“无需补充”；逐题基本说明按 C5 核对覆盖，再决定解释深度。
3. **按类选择补充点**：用下表检查与当前缺口相关的项目，选择必要说明。分类描述学习作用；文字、公式、图形、表格等表达形式应服务于同一个理解问题。
4. **补足依据，写到够用**：从原句找出理解所需的定义、判据或数量关系，用简短说明或直达来源补足，让学生把依据应用到本题。优先沿用原题用词；必要的新术语就地解释它对应的原文含义。例子、反例、图示及其他方法按直接帮助当前问题的程度选用，足以支持预期学习动作后停止展开。修改学生可见文字时，使用项目的 [sloptrim](../sloptrim/SKILL.md) 压缩空话，保留数学条件与解释依据。
5. **按 C6 审核**：检查本次范围内的标题、预览、默认正文和折叠方法，包括未修改的既有内容与样本。按学习作用区分已解例题的理由说明与学生待完成的练习，不以问号或是否折叠判断代答。修订未通过项，区分可采用素材与待核实草稿。具体学习动作是内容目标；教学效果需由学生使用证据检验。

新增或调整入口、原文区域、关联目标，以及审核展示对应关系时，读取 [定位与关联审核](references/location-review.md)。

## 面板五槽位

学生看到的面板固定五个位置。内容按它们分工，不再按知识、方法、注意事项分栏。

- **标题**：陈述结论，不用问句，保持纯文本。
- **气泡预览**：一句话直接回应当前疑问；可用 LaTeX，但不写第二句。
- **正文**：按理解顺序推进，1–3 段；需要逐句说明的才写满三段，多数一条用一段承接到位。
- **方法提示**：默认折叠，确有可选路径或检查步骤时才写。
- **关联**：0–2 条，指向能直接提供依据的位置，不因相关就加。

深度按缺口定：不构成理解阻碍的位置不单独建条，只作为关联目标；拆分与合并的理由写进编写记录。

题目的覆盖清单（`questionCoverage.items`）里的条目必须保留方法槽，清单与带方法的条目一一对应；正文已承接的知识点、注意事项不再单独保留。不在清单里的条目不留 `questionGuide`，主体说明全写在正文。

## 组织说明

- 按理解依赖组织内容：先补必要的概念和条件，再对照原句解释含义、记法或理由；在相关处说清符号、比较基准和适用范围。已有充分依据时直接进入当前问题。
- 知识、方法、注意事项用于检查覆盖，学生看到的结构按理解过程组织。连续的解释可以写成连贯段落，分节用于区分实际不同的内容或任务，段数由解释需要决定。
- 提示应增加观察方向、可用依据或检查条件。仅重复题干的追问可以删去，让学生继续完成计算、判断和归纳。
- 正文与气泡预览中的公式与数学符号写成 LaTeX（行内 `$…$`，行间 `$$…$$`），由 MathJax 渲染；JSON 中的反斜杠写作 `\\`。标题保持纯文本，它同时用作搜索、图谱标签与校订比对。
- 公式只用于符号式子和带单位的量（`$2a+\\pi b$`、`$r=2\\ \\mathrm{cm}$`、`$126\\ ^\\circ\\mathrm{C}$`）。汉字写出的数量关系整段保持纯文字，不把其中的 `=`、`×`、`÷` 拆成单独公式：写“长×宽”“总数=单价×数量”。正文单独讨论某个符号时（“$-$”号），引号内写成公式仍属符号用法。

例如，解释“增长−2%”时，先说明增长率与百分数的含义，再解释原题“减少2%”为何记为−2%，最后说明正负号表示增减方向、百分数表示比例。增长率为0的判断留给学生。此例展示理解依赖，其他说明按各自缺口组织。

## 锚点与问题对齐

入口在哪里，学生就在哪里发问。一条补充只回答它的锚点那一句引出的问题：写前把锚点所在整句连同折行读完，列出当下会卡住的一点，再判断本条回的是不是这一点。

- **算式的构成**——两项各是什么量、单位从哪来、能不能相减、系数去哪了——挂在算式行，不挂在结论句。
- **结果级问题**——这个数是否合理、要不要取近似、答案怎么写——挂在结论句；同一处的推导细节不在结论处重讲。
- 一条内容对一个入口。锚点移动后，原位置若仍有独立的理解阻碍，再单独建条；没有就空着，不为每个位置凑条数。
- 气泡一句话里不出现无先行词的指代（“两块”“它”“这个值”），直接写名词：“三角形与圆孔”。涉及单位时说明系数只是数、不改变单位。

判断“标注错误”时，先分开两件事：核对 `locator` 与 `region` 是否真落在页面那句话上（框错位是定位问题，见[定位与关联审核](references/location-review.md)）；再看内容是否回答该句的问题。位置对、但答的是别处的问题，属锚点选择问题——改条目或移锚点，不是改坐标。

## 不同类型的补充点

以下是编写时的检查问题与素材选择，不是逐项填写的交付清单。

| 学习作用 | 优先检查的理解缺口 | 可选补充素材与停止边界 |
| --- | --- | --- |
| 引出问题 | 为什么提出这个问题？已有知识或方法在哪里遇到困难？ | 补出问题与已学知识之间的连接。研究动机已清楚时即可停止；背景材料仅在解释当前问题所必需时采用。 |
| 定义概念 | 哪些关键词决定概念的含义？对象需满足哪些条件？符号或取值范围是否影响辨认？ | 解释关键条件，必要时用例子与反例区分。以学生能判断对象是否符合定义为目标，避免仅换词复述。 |
| 陈述性质或结论 | 给定什么条件，才能得到什么结论？条件如何限制结论的使用？ | 拆清条件与结论，补必要的边界说明；逆向使用容易混淆时再澄清或给反例。解释足以支持当前判断后停止推广。 |
| 推导或证明 | 哪一步省略了依据？关键构造或推理服务于什么目标？前面的条件在哪里用到？ | 补关键跳步的依据，必要时先说明整体路线。原文已清楚的计算沿用原文，推理链完整后即可停止。 |
| 示范方法 | 为什么选择这个方法？关键变换希望得到什么形式？使用条件是否满足？ | 连接题目结构、方法选择与变换目的，区分方便做法和必须条件。达到理解当前方法的目标后停止，其他解法仅在有直接解释价值时加入。 |
| 练习 | 学生需要回顾什么，才能识别结构、检查条件或选择方法？ | 提供相关知识、教材回顾入口或简短提示，并说明与本题的关系。保留学生的关键选择、变形和推演；按 C5 检查提示是否已经代替作答。 |
| 探究 | 应观察或比较什么？哪些现象可支持猜想？怎样验证，现有证据能说明到什么程度？ | 补观察方向、对照线索与验证要求。保留学生形成猜想和执行验证的工作，避免提示直接完成探究。 |
| 回顾与整理 | 哪些已学知识存在直接联系？容易混淆的方法，其条件有何区别？ | 补局部关系说明或条件对照，帮助学生组织当前已学内容。联系已清楚时即可停止，不因相关就扩展成完整图谱或新增知识目录。 |

## 样例：第 88 页例4

人教七上第 88 页（印刷 81）例4 的解答按行排布，同一段能提出不同层次的问题：式子由哪两块组成、每一块的单位从哪来、结果 73.94 合不合理。

```
解：三角形的面积为 ½ab，圆的面积为 πr²，这个
三角尺的面积 S = ½ab − πr²。
当 a = 10 cm，b = 17.3 cm，r = 2 cm 时，
S = ½×10×17.3 − 3.14×2² = 73.94（cm²）。
因此，这个三角尺的面积是 73.94 cm²。
```

**样例一：算式行上的单位说明（锚点移位的修正）**

原状：一条“cm乘cm才得到cm²”挂在末行结论句上，气泡写“长度乘长度得到面积，两块都以$\mathrm{cm}^2$计才能相减。”问题是结论句被追问的是“73.94 怎么来、合不合理”，而它答的是算式的单位；气泡里的“两块”没有先行词；也没有交代系数不影响单位。

改法：条目移到 `三角尺的面积 S = ½ab − πr²。` 这一行，正文按两项各自的单位来源重写。

```json
{
  "id": "ch3-area-value-unit",
  "title": "两项都是 cm²，才能直接相减",
  "preview": "三角形与圆孔都是$\\mathrm{cm}\\times\\mathrm{cm}$，同是$\\mathrm{cm}^2$才相减。",
  "paragraphs": [
    "$\\frac{1}{2}ab$中$a$、$b$都是长度，$\\mathrm{cm}\\times\\mathrm{cm}$记作$\\mathrm{cm}^2$；$\\pi r^2$中$r^2=r\\times r$，也是两个长度相乘，同样是$\\mathrm{cm}^2$。系数$\\frac{1}{2}$、$\\pi$只是数，不改变单位。",
    "两项单位相同，才能直接相减，结果仍记作$\\mathrm{cm}^2$。若$b$用$\\mathrm{cm}$、$r$用$\\mathrm{mm}$，要先换成同一单位再算；否则两个数不同类，减出来的数没有意义。"
  ]
}
```

**样例二：结论句上的结果说明（此处确有新的理解阻碍，才单独成条）**

```json
    "若算出的结果在 739.4 或 7.394 这一档，数量级就不对，要回头查单位和进位；若算出 99 左右，多半是漏减了圆孔。粗算只用来判断结果合不合理，写答案仍以准确计算为准。"
  ]

```

**样例三：同一页两种行的左界不同**

`三角尺的面积 S=½ab−πr²` 是“解：”句的接排行，左起与“解”对齐（x≈0.133）；`因此，这个三角尺的面积是 73.94 cm²。` 是缩进起排（x≈0.178）。region 的 x 要按该行首字实测，沿用上一行就会整体右移约 0.045（屏幕上约 30 px，框会切掉行首几个字）。含 ½ 或上下标的行按墨迹高度给 height（约 0.034），纯文字行用 0.025。量框与调框的方法见[定位与关联审核](references/location-review.md) 的“框的边界”。

## 编写记录与交付

沿用项目已有格式，或用简短记录保留：

- 教材位置及核对状态；概括、原文引用与补充解释的来源区分。
- 学习作用、具体理解缺口，以及预期支持的学习动作。
- 面向学生的补充说明；如有知识关联，记录目标位置、关系和查看目的。
- 改完气泡或正文后需发布才在应用中生效；位置与区域改动随前端构建生效，不进发布内容。发布后运行 `node --experimental-strip-types scripts/check-cloud-content.mjs`，只有返回 `fullSourceEquality: true` 才算同步完成。

面向学生的正文只呈现必要的解释与回顾入口。分类、审核状态等信息留在编写记录中。

对按 C2 取舍而无需补充的一般段落，简述理由即可。未核实的关联保留为待办出处，不显示为精确页码链接。

## 后续优化

依据实际教材片段、审核问题或学生使用反馈，修订对应类型的补充点。先修正具体问题，确有通用性再形成通用指导，并删除失效或重复内容。

类型含义的变化维护在 `GLOSSARY.md`；已获授权的目标、范围或验收变化维护在 `docs/SPEC.md`。把学生表现与作者判断分开记录，后者只能作为待检验的内容建议。
