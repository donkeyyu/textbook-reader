# 小岛书桌

DonQ 已批准 Animal Island UI 风格原型用于正式界面。产品名称仍为“课本解读”；原型中的示意图谱、单页翻阅和布局切换条不属于功能要求。

## 使用依据

- 改动前查看 [DESIGN.md](../../../DESIGN.md) 的对应组件；颜色、字体、尺寸与状态值从 [island.css](../../../src/appearance/island.css) 读取并复用。视觉实现限定于 `data-ui-style="island"`，兼容读者保存的其他风格。
- 涉及阅读空间或操作取舍时，使用 [reader-ui-design](../reader-ui-design/SKILL.md)。行为与验收归 [SPEC.md](../../../docs/SPEC.md)，风格不能改变原文定位、关联返回、草稿与续读语义。
- [原型](../../../public/prototypes/animal-island/index.html)用于追溯外观选择；正式源码是当前实现依据。[上游库](https://github.com/guokaigdg/animal-island-ui)提供设计来源，不要求安装整库。复用上游代码或资产时保留其许可证。

## 设计规则

**纸面与薄荷。** 奶油纸色承托内容，暖棕用于正文，薄荷绿标识主要操作，薰衣草色标识导航选中。类型色仍区分概念、方法、问题、回顾与个人补充；图标和文字同时表达含义。原始教材图片保持原色、字体和公式排版。

**圆润而克制。** 界面采用圆润无衬线字体与清晰字重；长标题换行。按钮和短输入使用胶囊轮廓，面板使用较大的圆角。主要按钮使用暖色向下压印及按下反馈，普通按钮，包括图标、翻页和抽屉操作，使用奶油胶囊、暖色描边及轻微柔影，不能只换文字颜色。目录条目保留平面层级。装饰丝带只用于书架等展示标题；阅读正文和密集工具栏保持安静。

**粉笔边线。** 原文高亮与方法展开入口使用共享粉笔手绘轮廓，颜色沿用内容类型；定位坐标和原页图像保持原样。标题徽章与文字居中对齐，同行操作统一视觉尺寸，并检查旧 min-width/min-height 是否覆盖新尺寸。

**形状服务内容。** 设置等模态可用柔和有机轮廓，保留原生模态、焦点约束与关闭行为；裁切层不能切掉滚动内容、关闭按钮或焦点环。图标沿用具名 SVG，关闭与次要操作保持足够触区。

| 界面 | 应用规则 |
| --- | --- |
| 书架 | 真实封面为主体，纸色承托、暖棕书名、薄荷阅读按钮。书名、版本和续读位置分层；书本小伙伴插画避开内容与操作。空书架给出添加入口。 |
| 设置 | 风格样本、单选名称和说明形成一个可选对象；选中、焦点、保存失败各自可辨。窗口过长时内部滚动，窄屏操作完整可见。 |
| 目录 | 层级通过缩进、字重及展开图标表达；当前项用薰衣草底和可辨状态，悬停弱于选中。长章名完整换行，目录开合保留浏览现场。 |
| 阅读页 | 纸色只用于教材外壳；原页连续滚动，页码仍居中于教材列。工具按钮轻量，标记与原文框继续使用内容类型语义。 |
| 图谱 | 暖色画布、清晰棕色标签与柔和连线；焦点、邻居和未关联节点有强弱层次。节点关系以真实数据为准，不为画面好看增加连线。 |
| 解读抽屉 | 纸色正文、类型标记、圆润方法开关和整行关联入口。标题类型徽章大于旁侧操作图标；书本伙伴可用于预留边缘与淡背景，避开正文和操作。标题固定且不透明；关联目的紧邻入口，返回与关闭易找。个人笔记保留编辑、保存与错误状态。 |

搜索、账号、教材管理与编辑浮层沿用同一套输入、按钮、表面与反馈规则，避免只给六个主界面换色。正常、悬停、按下、选中、焦点、禁用、加载、空和错误状态均应有明确表达；错误保留恢复入口，不仅靠颜色提示。

## 核对

通过 [README 回归入口](../../../README.md#选择回归入口)选择受影响路径，按宽屏、窄屏及分屏窄容器核对。重点检查书架→阅读→解读→关联→返回，以及设置开合、长标题、缩放与面板调宽。保留键盘焦点、足够文字对比度及减少动态效果偏好；原页外观正确不等于学习效果已验证。
