# 05: 在笔记和个人正文中建立稳定的节点链接

**Blocked by:** 04：创建和维护不依附原文的个人节点。

**What to build:** 用户在两种编辑入口输入双括号，通过章、节候选选定目标，保存后点击链接打开对应内容。找不到时可主动创建节点。此路径不依赖图；反向引用和图中个人连线由 06 增加。

- [ ] 两种入口共用链接规则，默认笔记不额外生成节点；候选有章、节，同节重名再显示位置或摘要。
- [ ] 每个引用实例独立绑定稳定目标；同一笔记中的两处同名链接可指向不同节点。
- [ ] 插入普通文字、局部编辑、删除、撤销重做和刷新不交换绑定；纯文本粘贴按未绑定处理。
- [ ] 找不到时由用户主动创建并链接，取消不留空节点；无法确定的文本提示选择，不自动猜测。
- [ ] 代码、转义及未闭合内容不误建有效引用；自引用可导航，保留原始 HTML 不执行的规则。
- [ ] 目标改名不丢身份，删除后显示失效，新建同名节点不接管旧引用；默认内容更新移除目标也不得误连。
- [ ] 正文与绑定原子保存，失败保留草稿；实际浏览器完成输入、候选选择、导航及刷新，数据层覆盖引用身份边界。

规格覆盖：US15–20、29–30、34–35、37；T4、T6–7、T13。可与 03 并行，避免把编辑器工作不必要地阻塞在图渲染上。

依据：[详细规格](../spec.md)、[审查记录](../review.md)。规格中的实施建议仍是工程建议，不提升为用户已确认的技术选型。

验证：运行受影响测试、类型检查与构建，并完成本票浏览器路径；仅为存储迁移和链接身份补充数据层测试。
