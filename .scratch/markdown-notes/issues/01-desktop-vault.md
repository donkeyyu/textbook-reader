# 01: 桌面打开笔记库并保存第一篇笔记

Status: ready-for-agent
Category: enhancement

**What to build:** 在 Electron 中复用现有前端，用户选择一个本地笔记库，读取手动文件或新建笔记，编辑保存后关闭并重新打开。网页版继续保持原有行为；提供后续票可使用的两平台最小安装产物，发布签名与分发由 12 收口。

**Blocked by:** 无（获准实施后可首先领取）

## Acceptance criteria

- [ ] macOS 可启动安装产物并选择一个笔记库；Windows 实机操作验收移交 13；取消选库不创建或改写文件，不破坏当前内容。
- [x] 可浏览并打开手动创建的 Markdown，包括缺少内置元信息的文件；读取和扫描不补字段、不改时间。
- [x] 可新建、编辑、立即保存并重开笔记；持久内容使用已确认的 Markdown/YAML 格式和库布局，未知属性保留，前端不另存一份正文作为唯一依据。
- [x] 新笔记生成 UUID；新建创建与更新时间为首次成功保存时间。手动文件缺失创建时间保持未知，缺失 ID 仅在保存或明确纳入管理时补齐。
- [x] 按 R15“时间维护与外部文件变更”逐项核对：合法历史时间保留；正文、用户属性或 anchors 成功保存修改才更新内置更新时间；仅补 ID 不补造时间；异常时间保留并提示，自定义时间不覆盖内置时间。
- [ ] 上次笔记库、窗口布局、光标与滚动位置保存在库外本机应用数据目录并按库隔离；重开恢复可用位置，无效位置仍可打开内容。切换库或关闭应用前保护未保存草稿，取消保持现场，不把草稿当作已保存内容。
- [x] 同目录新建重名时提供可用名称，不覆盖已有文件；高于支持版本的文件只读打开，异常 ID 或文件头不被静默重写。
- [x] 保存成功后才显示已保存；权限不足或写入失败保留草稿并可重试，已保存时间不提前推进。保存前检查磁盘版本并阻止已发现的冲突覆盖，完整冲突操作由 02 承接。
- [x] 主进程验证调用来源和库内路径，preload 只暴露明确操作；前端隔离、沙箱和 HTML 不执行的边界有效，路径穿越及指向库外的链接不能绕过边界。
- [x] 本地笔记编辑不依赖云端个人账号；旧网页版及旧云端个人内容保持原状。确定 Electron 版本与打包工具，使用打包前端而非开发服务器生成两平台最小安装产物，记录 macOS 基本读写和重开验证结果；Windows 构建与实际运行证据分别记录，后者由 13 验收。
