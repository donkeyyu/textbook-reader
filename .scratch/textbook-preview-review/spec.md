# 教材预习与复习：找页、续读与按需解读

> 当前适用性（2026-10-25 更新）：本文保留该轮任务形成与验收依据。A 节、A1–A4 及相关用户故事中的双页码显示／切换，已由 DonQ 后续确认的 [SPEC R7](../../docs/SPEC.md#r7-本轮确认的页面设计) 替代，后续实施和复验使用当前 R7。续读与方法按需展开已承接到 [SPEC R4](../../docs/SPEC.md#r4-续读与方法按需展开)。下文“当前”“尚未实施”描述规格形成时的状态，执行证据见[任务索引](README.md)；不据此恢复旧交互，也不改变仍待完成的真机、真人验收。

## Problem Statement

学生和家长需要围绕手中的教材，在预习时理解概念、符号与理由，在复习时回顾条件和知识联系。当前阅读器已经支持教材原位解读、知识关联和返回，但三个环节增加了使用成本：

- 拿纸书找内容时，用户看到的印刷页码与阅读器的文件页序不同，常驻页序没有明确说明区别。
- 隔天复习或刷新后，用户回到封面，需要重新寻找上次的教材位置；保存的笔记不能代替阅读位置恢复。
- 打开习题引导时，思路与方法立即显示。需要参考时很方便，但预习或自行回顾时，可能过早获得本应先尝试识别的结构。

不同先备知识的学生需要不同的查阅深度；家长需要可据以共读的解释。项目服务于教材理解，不以判断个体错误、完成课后作业或开展一对一培训为目标。分数层级仅是此前评审的模拟视角，不是用户分类规则。

## Solution

保留真实教材主导的阅读界面，完善一条连续路径：按课本印刷页码找到原页，按需查看解读，自主选择何时查看方法，查阅知识关联后返回，并在下次打开时继续阅读。

本轮交付三个功能，并按两条同等必要的验收线并行推进：产品线验证完整阅读路径和终端使用；内容与共读线验证解释质量，以及学生独读、家长共读中的实际表现。两线分别记录结果，不能互相替代。以下具体交互是本次规格形成的实现选择，不表示此前评审中的所有建议都已成为项目需求。

### A. 明确两种页码并支持纸书定位

- 常驻导航区明确显示“文件页序 N/202”；有已核对印刷页码时，同时显示“课本第 X 页”。无可见印刷页码时明确显示“无印刷页码”，不推算。
- 现有跳页入口提供“课本页码”和“文件页序”两种输入模式。默认使用课本页码；文件页序入口始终可用，保留封面、目录等全部页面的访问能力。
- 按已核对的全书页码映射定位，匹配印刷页码标签；不能用固定偏移或仅用有解读的页面反推。
- 未找到课本页码时说明原因并提供切换文件页序的方式，不改变阅读位置。空值、格式错误和文件页序越界同样保留当前位置。
- 知识关联目标明确标注“课本第 X 页”；没有印刷页码时标注“文件第 N 页”。解读标题和正文继续不重复当前位置页码。

### B. 在本浏览器继续上次阅读

- 首次打开仍从封面开始；已有有效阅读记录时，刷新或重新打开自动恢复上次阅读的文件页序和页内相对位置。
- 阅读记录按教材版本身份隔离。不同教材不能共用记录；记录损坏、版本不匹配或页序无效时回到封面，并保留正常阅读能力。
- 恢复适应窗口尺寸变化；恢复的是同一段原页附近，而不是旧视口中的绝对像素。
- 只恢复原页位置，不跨刷新恢复解读面板、知识关联历史或未保存草稿。当前会话内的返回上下文继续保留原有行为。
- 沿用已保存笔记和个人补充；阅读记录与其隔离，任一记录失效不得覆盖另一类内容。
- 读取或保存阅读记录失败时，用简短提示说明无法恢复或记录位置，用户仍可继续阅读；避免滚动时重复弹窗。

### C. 由读者选择何时查看题目方法

- 首次打开一条习题引导时，显示考查知识点、注意事项、相关知识和原有必要说明；“思路与方法”默认收起，有清楚的展开入口。
- 展开和收起不重置教材位置，不丢失个人笔记草稿，不影响密集入口中题目的选择。
- 查阅知识关联并返回时，恢复来源习题引导的方法展开状态；直接重新打开一条引导或刷新后重新进入时，默认收起。
- 题目覆盖和四项基本说明继续保留。例题的教材原解答、概念解释、推导解释保持可读，不因方法收起而隐藏原教材。
- 审核习题引导的标题、预览和默认可见正文，避免把原本收起的方法逐字搬到这些位置，使按需展开失效。标题仍需清楚标明题号或主题。
- 收起方法只是查阅选择，不承诺阻止所有知识线索。内容仍须保留学生的关键判断和推演，不以“放在折叠区”作为代解的理由。

### D. 内容与共读验证

- 与产品线并行准备教材样本、审核记录和观察任务，不等待全部功能完成才开始内容检查。优先复用同一批教材位置，使内容问题与交互问题可以对照。
- 六章各选至少一处补充，样本整体覆盖概念含义、推导理由、方法条件与知识关联。记录原页、理解缺口、预期学习动作和判断依据；实际修改的说明另按内容标准逐条审核。
- 围绕样本准备三类观察任务：学生首次预习后的复述或辨认；学生复习时解释条件与关联、隔天重返阅读；家长依据材料与孩子讨论一个含义或理由问题。
- 学生覆盖不同先备知识，家长兼顾数学熟悉与不熟悉的情况。成绩仅作背景，不以分数代替先备知识判断。实际招募、参与者与时间需由项目负责人协调，不据此自动联系任何人。
- 记录读前理解、查阅过程、读后回答、所获提示与困难，区分界面障碍、内容障碍和已有知识缺口。学习表现不能仅用“看懂了”、点击次数或家长满意度代替。
- 形成样本结论、问题修订及受影响样本的复核记录。不要求结果必须正向；若解释没有帮助或增加干扰，如实记录并说明后续处理。样本观察不能外推为全书有效或提分证据。

## User Stories

1. As a 预习学生, I want 按纸书的印刷页码找到同一页, so that 我能直接查看正在预习的内容。
2. As a 复习学生, I want 清楚区分印刷页码和文件页序, so that 我不会把不同数字误认为跳页错误。
3. As a 学生, I want 按文件页序访问封面、目录和无印刷页码的页面, so that 我仍能阅读完整教材。
4. As a 学生, I want 输入不存在的课本页码时得到明确提示, so that 我能修正输入而不丢失当前阅读位置。
5. As a 学生, I want 在导航收起时也能查找课本页码, so that 我无需为找页反复改变阅读布局。
6. As a 手机读者, I want 跳页模式和当前页码含义清楚可见, so that 我能在小屏幕上完成同样的查阅。
7. As a 家长, I want 按孩子纸书上的页码定位, so that 我们能讨论同一段教材。
8. As a 复习学生, I want 再次打开时回到上次阅读区域, so that 我不必重新翻找。
9. As a 学生, I want 刷新后继续阅读, so that 临时中断不会让我从封面重新开始。
10. As a 学生, I want 改变窗口尺寸后仍恢复到同一段附近, so that 阅读位置不会因版面变化而失效。
11. As a 首次使用的学生, I want 从封面开始完整阅读, so that 没有历史记录时也有明确起点。
12. As a 学生, I want 不同教材的阅读记录互相独立, so that 我不会恢复到其他版本的位置。
13. As a 学生, I want 阅读记录失效时仍能正常打开教材, so that 一条坏记录不会阻止学习。
14. As a 记笔记的学生, I want 续读功能保留已经保存的个人内容, so that 我此前的记录不会受到影响。
15. As a 预习学生, I want 先看教材问题再自行决定是否展开方法, so that 我可以先尝试识别结构。
16. As a 带着疑问查阅的学生, I want 一个明确入口即可展开完整方法说明, so that 获得帮助不需要额外测评或问答。
17. As a 复习学生, I want 查阅方法前仍能访问相关知识, so that 我可以先回顾定义和条件。
18. As a 学生, I want 查阅知识关联后恢复原来的方法展开状态, so that 我能继续被打断的阅读。
19. As a 学生, I want 收起方法时保留当前教材位置, so that 我可以回到原文继续思考。
20. As a 使用键盘的读者, I want 操作跳页和方法开合并获得明确状态反馈, so that 我可以不依赖鼠标完成阅读路径。
21. As a 在密集题目页阅读的学生, I want 先选择题号再决定是否展开方法, so that 我不会把相邻题目的说明混在一起。
22. As a 正在记笔记的学生, I want 方法开合不清除草稿, so that 阅读和记录可以连续进行。
23. As a 已有较好基础的学生, I want 跳过已经理解的方法说明, so that 我能把注意力留给条件和边界。
24. As a 数学不熟悉的家长, I want 教材解释与个人笔记保持可区分, so that 我能知道共读时使用的内容来自哪里。
25. As a 共读家长, I want 用同一条教材解读讨论含义和理由, so that 我可以支持孩子理解而不必承担批改或培训职责。
26. As a 内容审核者, I want 检查默认可见文字是否重复完整方法, so that 折叠交互能真正提供查阅选择。
27. As a 老师, I want 每条修改后的补充仍对应真实教材位置并有解释增量, so that 推荐学生查阅时有可核对的依据。
28. As a 产品负责人, I want 将功能验收与学生学习表现分开记录, so that 我不会把运行通过当成学习效果成立。
29. As a 内容审核者, I want 与交互实现并行核对教材样本和学习动作, so that 内容问题能及时反馈到实现与解释修订。
30. As a 共读家长, I want 让实际共读中的困惑被记录, so that 材料是否支持讨论可以依据使用表现判断。
31. As a 产品负责人, I want 分别看到产品线与内容共读线的证据和未完成项, so that 一条线通过不会掩盖另一条线的缺口。

## Implementation Decisions

以下是本规格采用的实现约束；本轮仅生成规格，尚未实施。

- 复用现有教材目录、教材内容、阅读器、返回上下文和个人内容模块，不增加独立学习中心或新的后端服务。
- 页码映射归教材目录模块管理。将已经核对的全书映射纳入运行时目录数据，覆盖有解读和无解读页面；保持原始来源可追溯。无可见印刷页码保存为空，印刷页码使用标签语义，不作位置主键。
- 页码解析返回唯一目标或可解释的未找到结果。当前教材若出现重复印刷标签，应在数据检查时报告并消除歧义，不静默选择第一项，也不为未来教材预建复杂消歧界面。
- 知识关联继续使用明确的教材位置标识，不改成印刷页码引用。现有 ADR 仍是 proposed 状态；本实现沿用当前明确位置引用，不宣称该 ADR 已正式采纳。
- 阅读记录包含记录格式版本、教材身份、文件页序和页内相对位置；单独持久化，不改写个人笔记存储格式。复用现有阅读定位计算及浏览器本地存储方式。
- 初始化先校验并恢复记录，再启用位置写入。对滚动写入节流，在页面隐藏或离开前尽力保存；不得依赖卸载时的异步请求保证成功。
- 自动恢复只持久化原页阅读位置；不存储关联历史、筛选状态、方法状态或未保存草稿。关联目标也属于当前阅读位置，刷新时恢复该目标页，返回链不跨刷新延续。
- 方法展开状态由习题引导呈现和会话返回上下文共同管理。复用已有题目方法数据，不复制为新的内容版本。
- 默认可见文字的审核优先改写重复方法的标题和预览，保留可识别的题号与主题。必要的概念线索可以保留，不追求让读者看不到任何解题相关知识。全部受改动内容需重新核对学习动作与数学条件。
- 使用可由键盘操作、能表达展开状态的控件；遵循现有简洁风格和上下/左右分区。初步不增加预习模式、复习模式或按成绩切换的界面。
- 内容审核记录与学习观察记录分别维护。内部学习动作不直接批量显示为学生测验，不因此增加测评系统。

## Testing Decisions

- **双线并进、分别验收**：产品线的边界是阅读器的用户可见完整路径；内容与共读线的边界是具体教材片段中的理解和讨论任务。两线同等必要，内容共读验证不作为可选附录。共享教材样本，但分别报告证据与结论。
- **产品线**检查找页、打开解读、自主展开方法、关联查阅、返回、刷新与重新打开的结果和阅读连续性，不检查 React 状态变量、组件拆分、CSS 类名或文案逐字一致。
- **现有测试基础**：教材目录测试已覆盖全书页序和资源；内容引用测试已覆盖版本、位置、关联和逐题清单；阅读会话测试已覆盖滚动定位与尺寸恢复；个人内容测试已覆盖本地保存和读写失败。已有浏览器脚本覆盖关联返回、折叠选择和焦点恢复。实现前核对脚本入口与当前页码编辑交互，不把旧脚本能执行视为既定事实。
- **必要的低层测试**只补两处：教材目录的印刷页码解析与无结果边界；阅读记录的校验、教材隔离与存储失败。复用现有模块边界，不为测试新增通用框架或服务层。
- 主路径用真实当前教材的已核对样本；存储损坏、写入拒绝等边界可以用受控替身。页码对应关系以原页及已有全书核对记录为依据，不在测试中用固定偏移生成期望结果。
- 桌面和窄屏分别运行路径 Q1；覆盖单条入口与合并入口，使用键盘检查操作与返回焦点。保存位置应先等待记录稳定，再验证刷新及重新打开；另检查初始化不会覆盖旧记录。
- **内容与共读线**按 D1–D3 执行。内容检查依照项目 C1–C6：实际修改逐条审核；六章各抽至少一处解释增量和原图对应关系。字段齐全、测试通过及未显示答案都不能单独证明内容质量。
- 真实手机检查列为独立终端验证。若无法取得设备，交付明确列出未验证项，不能用构建成功或 DOM 存在替代视觉和触控结果。
- 学习观察使用不同先备知识的学生及家长，执行 D 节规定的预习、复习与共读任务。记录任务、帮助程度、实际回答和困难，不设未经讨论的提分或通过率承诺。观察用于发现理解增量与障碍，不冒充对照实验或因果证明。
- 工程实现可以先达到自身完成条件；整体规格按 D4 验收。缺少参与者或设备时，继续可独立完成的实现、内容审核和观察方案准备，明确列出待验证事项，不将整体规格标为完成。没有真实学生使用证据时，学习效果继续标为未验证。
