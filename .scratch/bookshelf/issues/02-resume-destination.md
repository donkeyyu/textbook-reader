# 02: 重开应用时恢复最后停留页面

**Parent:** [书架、教材管理与启动恢复规格](../spec.md)

**What to build:** 读者在书架离开后重开仍回书架，在书中离开后重开恢复同一教材版本及页内位置。异常或旧记录不会阻断阅读，也不会覆盖有效个人内容。

**Blocked by:** [01：首次进入书架、添加教材并开始阅读](01-shelf-and-reading.md)。

- [x] 分别保存最后停留页面和每本教材阅读位置；存在阅读记录不等于应自动打开教材。无有效启动目的地时进入书架并展示已保存成员，仅成员为空时展示空状态。
- [x] 上次停在书架时刷新或重开仍显示书架；上次停在书中时恢复同一教材版本、文件页序和页内相对位置。
- [x] 窗口尺寸变化后仍恢复页内相对位置；不同教材版本的阅读记录互不覆盖，书名不作为身份。
- [x] 仅在导航成功后更新目的地；草稿保护取消返回时保持阅读页与原目的地。刷新不承诺恢复未保存草稿。
- [x] 只有旧单本阅读记录、没有新启动记录时进入书架；添加并打开原教材后可继续旧位置，初始化不先以封面覆盖旧记录。
- [x] 上次教材不可用或不在书架时回到书架并说明原因；教材可用但位置损坏、版本不匹配或页序无效时沿用封面回退规则。
- [x] 本地记录损坏或读写失败时有必要提示，保留可用阅读入口，不清空其他有效记录或个人内容。
- [x] 跨刷新只恢复教材原页位置，不新增解读面板、知识关联返回历史、筛选或方法展开状态恢复；不新增跨设备同步或分享链接协议。
- [x] 通过浏览器验证阅读后重开、返回书架后重开、改变屏宽后重开、取消返回及旧记录兼容，并验证已有成员但没有启动记录时仍展示成员且可打开教材；沿用现有阅读会话测试覆盖必要的无效记录与版本隔离行为。
- [x] 对不可用教材和多版本隔离使用最小测试夹具，不依赖任务 03 的移出界面，不向正式教材库添加虚构教材。
- [x] 更新启动恢复需求及实际检查说明；运行受影响的既有检查并记录结果。
