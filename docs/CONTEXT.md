# 课本解读 · 项目背景

## 定位

“课本解读”以学生熟悉的课本为阅读入口，在原有段落、知识点、例题步骤和习题旁补充解释，并串联教材中的相关内容。核心场景是学生阅读教材、理解教材和借练习回顾教材。

当前聚焦初中数学。最初愿景包括小学、初中教材及视频等内容，后续讨论收敛到先验证教材理解场景。先判断这一细分场景的内容价值，再考虑扩大教材范围或增加内容形式。功能要求与验收条件统一见 [SPEC.md](SPEC.md)。

## 想法来源与应有的证据边界

DonQ 提出的三个启发：

1. “精通课本就能拿高分”的说法，提示教材中的句子和安排可能包含学生未注意到的意义。
2. 《陶哲轩教你学数学》带来的启发：联系题目给定信息、问题与相关知识，考虑应用条件和边界。
3. 波利亚《如何解题》带来的启发：通过问题和回顾推动解题思考。

这些是项目动机，不是已经验证的教学效果，也不是本项目已核实的逐字引文。项目希望检验的是：把教材中隐含的理由和知识关系解释清楚，是否能帮助学生更独立地理解和运用，而非承诺分数提升。

## 为何从课本出发

课本提供学生熟悉的章节顺序、表述和例题上下文。把解释与关联放回这些位置，有望减少学生在抽离的知识列表中寻找入口的成本。知识关系仍然重要，但它服务于当前阅读问题，而不要求学生先理解一张完整图谱。

范围、内容标准和阅读逻辑统一维护在 SPEC.md 第1至3节，确认状态以其中标注为准；样例偏好见其第5节。

## 需要检验的价值假设

| 假设 | 可观察证据 | 尚不能作为证据的现象 |
| --- | --- | --- |
| 补充理由能改善理解 | 学生能用自己的话说明变换目的及条件 | 学生表示“看懂了” |
| 教材关联能支持回顾 | 学生能找到相关内容，并说明与当前步骤的关系 | 点击次数增多 |
| 提示能支持独立应用 | 面对变式，学生能选择下一步并解释理由 | 跟着提示复现同一道例题 |
| 附着教材的说明能保持阅读连续性 | 阅读关联内容后能回到原任务，说明帮助大于干扰 | 页面美观或交互运行正常 |

以上是建议的评估视角，并非 DonQ 已确定的研究方案或效果门槛。当前没有足够学生使用证据证明以上假设成立。后续评估宜用具体教材片段、学生复述和变式任务观察；评估形式与规模尚未确定。

## 待决定事项

- 首批教材的版本、覆盖章节与内容密度。
- 是否逐段覆盖，以及不同内容应解释到什么深度；早期逐段解读的愿景尚未被确定为首批交付范围，也未被撤销。
- 内容审核人员、更新责任，以及跨版本对应关系的维护方式。
- 如何照顾学生已有知识差异；分层内容是可评估的方式，尚未确定。
- 主要终端、触屏与窄屏阅读方式。
- 后续是否引入视频、其他学科及其他教学服务。

上述事项不是本轮待开发清单。公开提供教材之前，需要确认对应使用与传播授权；当前提供的文件仅是样例依据，不能据此推定公开分发权限。
