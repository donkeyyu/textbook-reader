# 原文区域定位

本项目的内容范围以 SPEC R8 为准：整题引导覆盖完整题干、小问和所需图表；
具体语句或步骤的解读精确覆盖该对象。先从解读内容确定范围，再找坐标。

## 从候选位置到内容边界

1. 用原生文本、题号、索引标签找到候选页。核对该页的章节、题组和相邻题号，
   同名“练习第1题”不能只按标题匹配。文本搜索框只说明命中的字在哪里。
2. 查看完整页图，确认起点和终点。沿缩进、行距和编号追踪续行；数学公式、
   分式、填空线、选项及配图可能没有可检索文本。查看下一题的起点作为边界证据。
3. 按原图完整尺寸计算坐标：`x=left/W, y=top/H, width=(right-left)/W,
   height=(bottom-top)/H`。缩放图或裁图上的坐标先还原到原图，包含裁剪偏移。
   页边距属于整页坐标系。标记入口 `marker` 与内容框 `region` 分别定位。
4. 同一对象跨页或有分离图表时，保留主 `page/region`，将其他区域写入
   `additionalRegions`，每项含 `page`、`region`、`sourceImageSha256`。
   同页分离图表也可使用该字段。逐区绑定对应原图哈希，避免用一个大框包含无关题目。
5. 叠框复核完整内容与相邻内容，才更新正式 JSON。自动文本框、OCR 和行号
   均为候选依据；坐标合法、哈希正确、无警告不能证明框选完整。

## 生成可核对的证据

在仓库根目录运行。工具只读取定位数据，不改写内容或审核状态。
使用 `--pages` 或 `--id` 限定本次范围，避免一次生成大量重复页图。

```sh
python3 .agents/skills/index-pdf-content/scripts/review_locations.py \
  materials/textbooks/人教版-数学-七年级上册.pdf \
  content/grade-7-volume-1/locations.json \
  --id ch1-practice-p5-1 --output /tmp/location-review
```

多个定位文件可依次传入；`--id` 可重复，`--pages 12-13,87` 指 PDF 页序。
筛选页范围会只输出范围内的区域；检查跨页题时优先按 ID 筛选，以包括全部续区。

- `review.html`：每个区域独立叠在完整原页上，保留周围内容，便于发现漏行和误包。
  打开页面检查原图；需要更细时放大。文件包含教材页图，按本项目材料保留规则使用。
- `review.json`：实际页集合、原文位置、区域、来源哈希、带编号的归一化文本行。
  `possiblyCutLines` 标出框与文本行部分相交的情况。短语级解读可能合理，需按范围判断。
- 文本提取失败时保留视觉输入并记录 warning。图表、缺失文本和完全漏掉的续行
  不会可靠地触发警告，因此仍需检查完整对象和相邻页。

修正后重跑叠框，记录实际核对的 ID、PDF 页序、未解决项及边界依据。
若只是抽查或检查候选集，交付时明确范围；不将其描述为全书复核。
产品内还需检查选中后的框、打开解读后的框、缩放/分屏后的框一致；
跨页内容切换页面后仍有相应框，关闭解读后撤销。浏览器入口见 README。
