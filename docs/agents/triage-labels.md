# Triage Labels

| 技能中的角色 | 本地 Status 值 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待负责人评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格明确，可由 agent 实现 |
| ready-for-human | ready-for-human | 需要人工实现 |
| wontfix | wontfix | 不予处理 |

分流任务时，用表中对应值更新文件开头的 `Status:`。
