# 02: 外部编辑与自动保存冲突保护

Status: ready-for-agent
Category: enhancement

**What to build:** 用户编辑笔记时，应用识别磁盘变化，自动保存有效修改，并在冲突时保留磁盘文件和编辑草稿供用户选择。

**Blocked by:** 01：桌面打开笔记库并保存第一篇笔记

## Acceptance criteria

- [x] 有效内容自动保存，快捷键可立即保存；未保存、保存中、已保存和失败状态与实际写入一致，快速连续编辑不会被旧响应覆盖。
- [x] 外部新增、修改、删除可在界面和内存索引中体现；无编辑草稿时重新读取，有草稿时暂停自动覆盖并提示。
- [x] 冲突可查看差异、将草稿另存为新笔记、采用磁盘版本；采用前保护未保存内容，取消操作保持现场，首版不自动合并。
- [x] 文件暂时不存在、只读、被外部程序替换或写入失败时不丢草稿，不伪报成功；有可重试或另存路径。
- [x] 无效 YAML 保留原文并提示，不通过重建文件头丢弃字段；外部改动不自动维护内置时间，文件修改时间与笔记更新时间区分。
- [x] 重复 ID 显示冲突，不任意绑定目标；用户可指定副本为新笔记。应用内复制产生新 ID，采用新建时间，保留原 AI 来源引用。
- [x] 落地可恢复写入与失败处理，验证写入中断及保存前后外部变化；不将一次预检查视为完全避免竞态的保证。
- [x] 文件监听和索引更新本身不写入 Markdown；未知字段保持，自动保存不因监听自身写入而循环触发。
