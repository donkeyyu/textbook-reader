# 课本解读 · 岛屿书桌样式提案

状态：2026-10-28 原型提案，供 DonQ 选择。不是已确认需求，不替换 DESIGN.md 或 SPEC.md。原型内数据仅用于交互展示，不写入账号、书架或阅读记录。正式接入仍需完整阅读路径验证。

依据：[Animal Island UI](https://github.com/guokaigdg/animal-island-ui)，提交 `1cdab9d45e3675082df381c3575b36c6743cb854`。参考其 `docs/design-system/design-tokens.md`、`design-rules.md` 和组件规格。许可证见同目录 THIRD-PARTY-LICENSE.txt。本提案选择相似元素，并为教材连续阅读、图谱和原文标记定制组合；不宣称已经安装或完整使用 React 组件库。

## 设计方向

采用奶油纸面、暖棕文字、薄荷绿操作、圆润控件。书架可带少量岛屿式装饰；阅读区优先留给原文。装饰、丝带标题和立体按钮只出现在需要强调的位置。教材原图不染色、不换字体、不重排公式。界面风格不改变类型含义、原文定位、关联返回及草稿保护。

两个待比较的结构：A 在宽屏右侧展开解读，适合对照；B 在教材下方展开解读，适合长段落。窄屏均优先保留教材可见范围。两者共享视觉语言，选择布局不自动成为产品要求。

## 基础样式

| 用途 | 值 | 使用边界 |
| --- | --- | --- |
| 全局底色 | `#f8f8f0` | 外壳、书架 |
| 内容表面 | `#f7f3df` | 设置、解读、面板 |
| 次级表面 | `#f0e8d8` | 分区与工具承托 |
| 输入表面 | `#fffbe7` | 输入框，不默认加厚阴影 |
| 标题文字 | `#794f27` | 标题、导航、按钮 |
| 正文文字 | `#725d42` | 解读正文与标签 |
| 辅助色 | `#8a7b66` / `#9f927d` | 非关键装饰与边界；正文小字需检查对比度 |
| 主色 | `#19c8b9` | 操作面、选中强调；搭配深色文字 |
| 主色悬停 / 按下 | `#3dd4c6` / `#11a89b` | 主按钮反馈 |
| 主色浅面 | `#e6f9f6` | 选中区域 |
| 边线 | `#c4b89e` | 输入与面板边界 |
| 导航选中 / 悬停 | `#b7c6e5` / `#d6dff0` | 库原有薰衣草导航色，当前项还须有标记 |
| 成功 / 警告 / 错误 | `#6fba2c` / `#f5c31c` / `#e05a5a` | 图标、边线、浅面；消息正文用深色 |
| 焦点 | `#ffcc00` | 输入、选择控件；按钮用薄荷绿并加外距 |

库中淡色文字与彩色卡片的白字不能直接视为可访问。正式实现须对真实前景背景组合核对：普通文字至少 4.5:1，大字和必要控件边界至少 3:1。必要时用深棕文字，保留库色作为填充。

类型色沿用项目含义：概念 `#0066cc`、方法 `#7046b5`、题目 `#9b5a00`、回顾 `#00766d`、个人 `#b13d65`。类型色配图标及中文名称，不用薄荷绿覆盖所有节点。状态色与内容类型色分开使用。

| 属性 | 提案 |
| --- | --- |
| 字体 | 英文数字 Nunito；中文 Noto Sans SC；后备 PingFang SC、Microsoft YaHei、sans-serif |
| 字号 | 页面标题 32–40px；面板标题 22–24px；小标题 18px；正文 16px；辅助 14px |
| 字重 | 正文 500；按钮与标题 600–700；辅助 400；不使用细体 |
| 行高 | 解读正文 1.75；标题 1.3；控件 1.4；正文行长约 28–38 个汉字 |
| 间距 | 4、8、12、16、24px；页面大区间距 32、48px |
| 圆角 | 小控件 12px，区域 18–24px，按钮与输入 50px |
| 边框 | 普通边界 1–2px；输入 2–2.5px；原文定位细框，不以粗框遮字 |
| 阴影 | 普通按钮暖色柔影；主按钮 `0 5px 0 #bdaea0`；卡片不普遍加阴影 |
| 图标 | 圆头线形、20–24px、约 2px 描边；图标按钮至少 44×44px |
| 动效 | 150–250ms，`cubic-bezier(.4,0,.2,1)`；优先 opacity、transform |

仅主按钮采用明显立体压下效果。卡片悬停最多上移 2px，不让教材和目录整体浮动。减少动态效果时取消位移和缩放。长文、公式、原页及输入内容不加逐字动画。

## 页面与组件配套

| 区域 | 选择的库元素 | 项目定制与视觉规则 |
| --- | --- | --- |
| 书架 | Card、Title、Button、Tooltip | 真实封面为主体；丝带用于“我的教材”；书名、版本、续读位置与按钮分组；装饰不占阅读入口 |
| 设置窗口 | Modal、Radio、Switch、Select | 库式有机 blob 外轮廓，内容保持矩形安全区；风格预览与布局选项有明确选中态；关闭、Escape 和回焦 |
| 教材选择 | Modal、Card、Button | 只展示真实可用教材；封面、版本、已添加状态清楚；不加入个人 PDF 上传 |
| 教材信息 / 更多菜单 | Modal、Tooltip、Button | 紧凑信息；移出为次要危险操作，撤销可见；不把移出写成删除内容 |
| 目录侧栏 | Collapse、Tabs、Input | 定制章—节树；章标题与节名分层，当前项有底色和标记；独立滚动；长标题换行 |
| 页面缩略图 | Card 的轻量外观 | 真实小图、选中描边；不逐图重复两种页码，页码集中在导航区 |
| 阅读页 | Button、Tooltip、Divider | 定制连续原页画布与局部工具栏；页码固定在书页区域居中；目录开合不移动当前原文位置 |
| 图谱 | Button、Select、Input、Tooltip | 自定义画布、节点和边；库无教材关系图替代品；节点类型色和文字标签保留，选中环与悬停分开 |
| 解读抽屉 | Drawer、Collapse、Tabs | 自定义原文联动与返回栈；浅纸色正文，标题、定位、关闭紧凑；内容独立滚动 |
| 搜索 | Input、Tooltip、反馈样式 | 自定义教材内容结果；标题、片段、类型分层，键盘可选择，选择后定位 |
| 账号 | Modal、Input、Button、Avatar | 邮箱与反馈，留在原阅读现场；原型只示意，不能伪报发送或同步成功 |
| 笔记与个人补充 | Input、Button、Collapse | 编辑区维持清楚文本边界；保存中、失败、冲突和草稿归属有文字提示 |

以上名称均来自库公开导出。目录树、教材画布、关系图、定位灯泡和关联返回是项目定制，不应包装成库已有能力。原型用原生 HTML/CSS 模拟外观；正式阶段再决定使用库组件还是复用现有组件皮肤。

### 书架

宽屏内容与页头共用约 1040px 对齐线，封面和文字采用舒展组合，主阅读按钮用薄荷绿立体样式。少量杏黄或薄荷装饰用于书架边缘。无书时保留“添加一本教材，开始阅读”及添加入口；已有教材不展示虚构数量或阅读积分。添加、继续阅读、更多菜单有明确层级。

### 设置

窗口宽度建议 560–680px，最大高度不超过视口减 32px，正文可滚动。大轮廓可用库式 blob，内侧留足空间，避免裁切焦点、关闭按钮和长文。风格卡使用圆角方形勾选标记；字体大小与布局选项展示当前值。原型选择只在会话中生效；不以演示设置替代 SPEC R14 的正式三种风格。

### 目录和阅读

目录建议宽 240–280px。阅读工具栏高 52–56px，正文画布在浅暖底上显示白色原页。全书保持可读，不能按有无解读过滤原页。当前章节底色、展开箭头、焦点环分别表达选择、层级和操作焦点。灯泡放在页边，不盖公式；原文框对应真实坐标。翻页、目录和页码跳转必须保持上下文。

### 图谱

画布使用低对比暖色点阵，点阵为装饰并可隐藏。默认边低对比，当前节点和相关边清楚，非关联节点降强调但仍可辨认。顶部放搜索与视图切换，局部提供缩放、定位当前节点及类型筛选。标签长度按真实标题处理，避免以无意义圆点代替内容。正式图谱须保留拖动、缩放及原文定位行为；原型可用固定节点演示选择关系。

### 解读

宽屏右栏建议 340–420px；底部模式初始约占教材列 35%。顶部有返回记录时先放返回与关闭，再放标题；无记录时标题与关闭同排。定位与内容类型靠近标题，正文不重复当前页码。方法提示按需展开，相关知识入口先说明查看目的再提供跳转。原文高亮、面板内容与选中节点使用同一类型语义。个人笔记放在解释之后，避免抢占默认阅读。

## 完整状态集合

| 状态 | 表现与操作 |
| --- | --- |
| 默认 | 暖棕文字、浅纸面；只有主要动作使用实色 |
| 悬停 | 背景加深或轻微上移；不显示仅鼠标可用的关键动作 |
| 按下 | 主按钮下移 2px、立体底影变薄；其他控件使用轻反馈 |
| 选中 | 明确底色、勾选或边标，并设置对应 aria 状态 |
| 焦点 | 独立外环与 3px 间距；选中态不能替代焦点态 |
| 禁用 | 降强调、不可操作；说明必要原因；与加载中区分 |
| 加载 | 局部进度与“正在加载”；保留当前原文，避免全页闪空 |
| 空列表 | 简短原因、下一步入口；搜索为空提供清除筛选 |
| 错误 | 图标、具体说明、重试；保留草稿与可用内容 |
| 保存中 | 明确正在保存，防止重复提交；不可提前显示成功 |
| 保存成功 | 简短反馈，不打断阅读；原型不宣称真实保存 |
| 撤销 | 移出后可见撤销；提示不覆盖页码或阅读主操作 |
| 内容缺失 | 明确关联目标不可用，保留来源与返回方式 |

## 响应式与可访问性

- 宽屏可并列目录、教材、解读；空间不足先收起目录，再将解读移到底部。不能靠缩小正文硬塞三栏。
- 手机使用单列书架内容或适合真实封面的紧凑布局；工具栏按用途换行；抽屉与窗口不超出视口，底部预留安全区。
- 图谱在窄屏可单独查看，教材与图谱切换保留选中对象。分屏不是手机强制布局。
- 图标操作提供中文可访问名称；所有功能可通过点击、触屏及键盘完成。窗口使用语义 dialog、焦点约束与关闭回焦。
- 控件最小触区 44px；长标题换行，200% 缩放时不丢失操作。表单有真实 label，错误通过文字关联输入。
- 页面使用 heading、nav、main、aside 等语义；结果更新使用温和 live 提示，不为每次图谱拖动播报。
- 装饰隐藏于辅助技术；教材图像保持可辨认，原型不能替代正式教材可访问文本方案。

## 原型检查与后续边界

先检查书架→阅读→目录→解读→关联→返回→书架，再检查图谱选中与解读联动、设置开关、两种布局和窄屏。视觉检查包括长标题、长段落、图谱标签、焦点与弹窗裁切。原型中的交互只证明设计可以展示，不证明真实持久化、202 页阅读同步、云端保存、教材定位正确或学习效果。

选择设计后，依据现有实现逐项接入并运行 README 对应回归；再更新正式 DESIGN.md。布局、字体和组件参数以最终批准版本为准。
