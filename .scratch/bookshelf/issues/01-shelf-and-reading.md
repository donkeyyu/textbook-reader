# 01: 首次进入书架、添加教材并开始阅读

**Parent:** [书架、教材管理与启动恢复规格](../spec.md)

**What to build:** 读者首次进入空书架，从现有教材库添加教材，打开阅读并返回书架。未登录也能完成这条路径；书架在当前浏览器保存，已有阅读记录和草稿保护继续有效。

**Blocked by:** None (can start immediately).

- [x] 无有效启动目的地时进入书架并展示已保存成员；仅成员为空时展示“添加一本教材，开始阅读”和添加入口。升级用户的旧阅读记录不被清空。
- [x] 教材选择展示实际可用教材的封面、书名和教材版本；仅有一本教材时如实展示，不新增虚构教材或上传入口。
- [x] 添加后留在书架；取消不改变书架；已添加状态明确，重复操作不产生重复项。刷新后保留书架成员。
- [x] 封面及阅读按钮打开对应教材版本。没有阅读记录时“开始阅读”进入封面；已有有效记录时“继续阅读”沿用原页位置。
- [x] 书架展示已有阅读位置，区分印刷页码与文件页序；不按固定偏移推算印刷页码。
- [x] 阅读页提供“返回书架”；未保存编辑沿用既有草稿保护，取消返回后仍能继续编辑，成功返回不清除已保存个人内容或阅读记录。
- [x] 未登录可添加、打开和阅读；保留阅读页现有账号入口。书架账号入口与跨页面会话整合由任务 04 完成。
- [x] 本地书架读写失败时提示原因，不伪报保存成功，不破坏既有数据，仍保留可用阅读入口。
- [x] 沿用既有视觉体系，封面为主体，桌面网格、手机两列、长标题换行；不依赖悬停完成操作，键盘焦点可见，选择窗口可关闭并归还焦点。
- [x] 复用现有浏览器入口，在桌面与手机验证首次进入 → 添加 → 阅读 → 返回，以及取消添加、去重、保存失败与草稿保护；覆盖已有成员但没有启动记录时，刷新后仍展示成员并可打开教材。运行受影响的既有检查。
- [x] 更新需求基线中首次进入应用与首次打开教材的区别，并记录实际书架布局；必要的小型重构先在本任务内完成，不新增后端服务或同步机制。
