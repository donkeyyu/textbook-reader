# 03: 下载当前教材并离线阅读

Status: ready-for-agent
Category: enhancement

**What to build:** 用户从桌面书架明确添加当前教材，下载原页、目录及所需资源，完整下载后可离线阅读。

**Blocked by:** 01：桌面打开笔记库并保存第一篇笔记；14：离线教材资源清单与校验准备

## Acceptance criteria

- [ ] 添加操作下载确定教材版本，生成或载入教材级目录和核对过的页码映射；不开放个人 PDF 上传，不迁移个人内容。
- [ ] 使用 14 固定的资源清单、版本身份、下载来源和完整性校验约定，实施时确定本机持久资源位置并记录决定；不得以开发目录文件可访问替代真实下载路径。
- [ ] 仅完整下载并校验通过后显示离线可用；中断、校验失败及资源缺失有提示和重试，不删除笔记或错误宣称完成。
- [ ] 完整下载后断网并重启安装产物，当前教材所有页面、目录、缩略图和必要字体可读取；文件页序与印刷页码仍分别核对。
- [ ] 离线资源不放入可随意清理的索引缓存；重建或清理索引不删除教材资源。重复下载不覆盖笔记。
- [ ] 书架添加、打开、移出与重加沿用保留个人内容及阅读记录的语义；确认过的版本在离线时不需要重新登录才能读取本地原页。
- [ ] 为 04 的初始笔记包导入保留明确添加动作与教材版本上下文，本票不因普通阅读或扫描生成笔记。

## Scope and verification

依据：项目规格 R15（2026-11-01 已确认方案）。实现前阅读当前规格、适用项目约定与技能。实施授权与调度见[任务索引](../spec.md#实施调度2026-11-01)；执行时仅领取依赖已完成的任务。

本票需完成对应完整用户路径及有意义的失败场景验证；后续整体验收不替代本票验证。实施过程中确定的字段、交互边界和验证结果记录在本票，不将静态原型细节自动升级为需求。不得迁移旧个人内容、增加学生笔记云端备份或扩大首版范围。
