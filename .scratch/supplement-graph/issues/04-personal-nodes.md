# 04: 创建和维护不依附原文的个人节点

**Blocked by:** 02：原有教材与个人内容迁入本地数据库后继续阅读编辑。

**What to build:** 在当前教材的个人内容入口创建、查找、阅读、编辑和删除自由节点，刷新后仍能读取。此任务可在图任务之外完成；图存在时同一内容源应自动包含这些节点。

- [x] 自由节点可没有教材位置，保存后具有稳定身份；不存在位置时不显示虚假定位。
- [x] 默认归属当前教材及明确的当前章节，可调整或选未归属章节；不猜测不明章节。
- [x] 同名节点允许共存，可通过章、节和位置或摘要辨认；个人类型沿用“我的补充”。
- [x] 节点有可回访的个人内容入口，不依赖尚未完成的图才能查找；取消创建不留空节点。
- [x] 编辑、改名、删除、刷新及保存失败均可从界面验证；保留旧的框选个人补充路径。

规格覆盖：US26–29、34–35；T8。此处只覆盖无链接时的节点维护，已绑定引用随改名删除的行为由 05 完成。

依据：[详细规格](../spec.md)、[审查记录](../review.md)。规格中的实施建议仍是工程建议，不提升为用户已确认的技术选型。

验证：运行受影响测试、类型检查与构建，并完成本票浏览器路径；仅为存储迁移和链接身份补充数据层测试。
