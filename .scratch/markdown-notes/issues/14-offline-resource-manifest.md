# 14: 离线教材资源清单与校验准备

Status: ready-for-agent
Category: enhancement

**What to build:** 从 03 拆出可独立完成的教材资源准备，给桌面下载器提供可核对的版本、资源清单与完整性校验依据。

**Blocked by:** 无

## Acceptance criteria

- [ ] 依据当前已核对教材版本、页面资源与目录，确定必须下载和必须随安装包提供的资源；覆盖全书原页、缩略图、目录映射、字体等离线依赖。沿用既有版本身份，不伪造页码或新的教材来源。
- [ ] 提供可重复生成和验证资源清单的最小脚本或产物；固定路径、字节数及内容哈希，缺失、损坏和越界资源不能通过。
- [ ] 记录下载来源与发布输入；区分真实可用远端、仅本地测试源和尚未发布的源，不把开发目录可读当作下载可用，不擅自公开发布教材。
- [ ] 交付 03 可消费的清单格式和失败语义，用真实 HTTP 下载样本核对哈希及损坏失败；完整桌面下载与断网重启由 03 验证。
- [ ] 不改写已有教材图像、索引事实或用户笔记；不涉及 AI 初始笔记包转换、Electron 下载界面或个人 PDF 上传。

## Scope and verification

依据 R15 教材获取与统一内容，实施授权见[任务索引](../spec.md#实施调度2026-11-01)。本票仅承接 03 的资源准备，不扩大首版范围。
