## 01：保存完成后才确认笔记已保存

**Blocked by:** None (can start immediately).

**What to build:** 在现有阅读器中完成异步保存的准备改造。读者持续编辑笔记、切换解读或关闭面板时，只有保存成功的内容才显示为已保存，较新草稿不会被旧请求清除。现有同步存储继续可用，本任务不提前迁库。

- [ ] 保存调用支持等待结果，确认与具体内容修订对应；失败保留草稿及可重试入口。
- [ ] 连续输入、延迟或逆序完成不覆盖较新内容；切换节点或关闭面板不丢待保存内容。
- [ ] 默认笔记自动保存与个人补充显式保存均沿用各自已有交互。
- [ ] 浏览器验证成功、失败及切换路径；现有同步保存行为仍通过。

规格覆盖：US35–36；T10 的异步保存部分。此项是明确缺口的前置改造，不扩展为阅读器整体重构。

## 02：原有教材与个人内容迁入本地数据库后继续阅读编辑

**Blocked by:** 01：保存完成后才确认笔记已保存。

**What to build:** 读者升级后仍能阅读完整教材、打开原有补充、编辑已有笔记和个人补充；刷新后读取本地数据库中的同一批内容。默认内容与个人内容迁移都在这一条可验证路径中完成。

- [ ] 默认节点保留教材身份、稳定 ID、类型、完整正文和教材位置；默认正文只读。
- [ ] 默认内容可重复导入与按修订更新，个人内容不被覆盖；阅读查询使用新的同一节点数据源。
- [ ] 旧个人节点 ID、标题、Markdown、页序、区域和节点笔记迁移完整；章节可核实则映射，否则未归属。
- [ ] 迁移事务失败不标完成、不删原数据；重试不重复，也不覆盖数据库中已经更新的个人记录。
- [ ] 存储失败、空间不足和跨标签冲突保留原数据与草稿；不主动上传个人内容。
- [ ] 用真实浏览器数据库验证首次升级、重复启动、中断重试、刷新以及旧标签写入冲突；默认内容更新也不丢个人内容。

规格覆盖：US31–36；T9、T10。推荐 IndexedDB，最终选择记录在任务交付中；不建设服务端或通用仓储。

## 03：从教材补充进入可探索的完整图

**Blocked by:** 02：原有教材与个人内容迁入本地数据库后继续阅读编辑。

**What to build:** 从当前 supplement 打开 Pixi 图，当前节点居中，读者可平移、缩放、搜索并选择节点，在图旁阅读解读及默认关联。此阶段沿用现有教材跳转，自动分屏由 07 增加。

- [ ] 一条 supplement 一节点；当前教材全部默认及已有个人节点进入图，包括孤立节点，同名不合并。
- [ ] 当前节点以可读比例居中；无当前节点时可进入概览。类型颜色与可读取名称一致。
- [ ] 平移、缩放、节点拖动和搜索选择可用；键盘有完整搜索与选择路径。
- [ ] 参考 family-tree 的现有实现与效果，或实际可获取的 Obsidian 材料，调校连线距离、节点排斥、碰撞间距和布局收敛；密集区与孤立节点均能找到并选中，不把节点或标签挤成不可操作的一团。
- [ ] 拖动节点时节点跟随指针、连线同步更新，邻近节点有连续的布局反馈；拖动不误触点击或画布平移，释放后平稳收敛，不突然重置全图或视野。具体参数以本册实测确定，不新增固定位置或跨刷新布局保存要求。
- [ ] 标签随缩放适当显隐，选中或搜索目标仍可辨认；用密集节点、孤立节点及不同缩放比例验证拖动与距离，并记录所用参考、调校结果和短录屏或连续截图。
- [ ] 默认关联保留方向和依据；只有原文的目标仍可跳转，不生成空节点。同位置多个补充不任意选一个。
- [ ] 点击节点只切换解读，保持方法默认收起、Markdown 安全和草稿保护；隐藏教材入口不删除图节点。
- [ ] 全册数据核验数量与身份；浏览器走通选择、默认关联、原文目标及键盘路径，记录性能观察的设备与数据量。

规格覆盖：US1–8、14、37；T1–3、T13–14。借鉴 family-tree 的渲染与布局交互，不复制家族模型。

## 04：创建和维护不依附原文的个人节点

**Blocked by:** 02：原有教材与个人内容迁入本地数据库后继续阅读编辑。

**What to build:** 在当前教材的个人内容入口创建、查找、阅读、编辑和删除自由节点，刷新后仍能读取。此任务可在图任务之外完成；图存在时同一内容源应自动包含这些节点。

- [ ] 自由节点可没有教材位置，保存后具有稳定身份；不存在位置时不显示虚假定位。
- [ ] 默认归属当前教材及明确的当前章节，可调整或选未归属章节；不猜测不明章节。
- [ ] 同名节点允许共存，可通过章、节和位置或摘要辨认；个人类型沿用“我的补充”。
- [ ] 节点有可回访的个人内容入口，不依赖尚未完成的图才能查找；取消创建不留空节点。
- [ ] 编辑、改名、删除、刷新及保存失败均可从界面验证；保留旧的框选个人补充路径。

规格覆盖：US26–29、34–35；T8。此处只覆盖无链接时的节点维护，已绑定引用随改名删除的行为由 05 完成。

## 05：在笔记和个人正文中建立稳定的节点链接

**Blocked by:** 04：创建和维护不依附原文的个人节点。

**What to build:** 用户在两种编辑入口输入双括号，通过章、节候选选定目标，保存后点击链接打开对应内容。找不到时可主动创建节点。此路径不依赖图；反向引用和图中个人连线由 06 增加。

- [ ] 两种入口共用链接规则，默认笔记不额外生成节点；候选有章、节，同节重名再显示位置或摘要。
- [ ] 每个引用实例独立绑定稳定目标；同一笔记中的两处同名链接可指向不同节点。
- [ ] 插入普通文字、局部编辑、删除、撤销重做和刷新不交换绑定；纯文本粘贴按未绑定处理。
- [ ] 找不到时由用户主动创建并链接，取消不留空节点；无法确定的文本提示选择，不自动猜测。
- [ ] 代码、转义及未闭合内容不误建有效引用；自引用可导航，保留原始 HTML 不执行的规则。
- [ ] 目标改名不丢身份，删除后显示失效，新建同名节点不接管旧引用；默认内容更新移除目标也不得误连。
- [ ] 正文与绑定原子保存，失败保留草稿；实际浏览器完成输入、候选选择、导航及刷新，数据层覆盖引用身份边界。

规格覆盖：US15–20、29–30、34–35、37；T4、T6–7、T13。可与 03 并行，避免把编辑器工作不必要地阻塞在图渲染上。

## 06：双向导航个人引用并在图中显示连线

**Blocked by:** 03：从教材补充进入可探索的完整图；05：在笔记和个人正文中建立稳定的节点链接。

**What to build:** A 引用 B 保存后，图出现一条无箭头个人连线，B 可查看来自 A 的引用并导航返回；编辑或删除引用时，图与详情按剩余有效引用同步更新。

- [ ] 不改写被引用节点正文；反向列表反映真实引用方向。
- [ ] 重复引用和双方互引聚合为一条个人连线，删除最后一处才移除；删除目标后失效引用不生成有效边。
- [ ] 默认关联与个人关联可区分，个人连线撤销不影响默认关联；自引用不画自环。
- [ ] 只在保存成功后更新持久化关联；失败或较早保存完成不能错误覆盖较新视图状态。
- [ ] 浏览器演示双向导航和连线变化；数据测试覆盖多处引用逐次删除、双方互引与目标删除，刷新后结果一致。

规格覆盖：US21–25、30、34–35；T5–6。不得另建与正文绑定不一致的独立可编辑边来源。

## 07：图与教材分屏定位并保留阅读现场

**Blocked by:** 03：从教材补充进入可探索的完整图。

**What to build:** 用户从图中的解读定位教材时，桌面默认分屏并标出原文；可调整宽度、隐藏关闭或重新打开任一视图。窄屏切换图与教材，各自位置不丢。

- [ ] 点击节点只切换解读；点击定位才打开分屏并滚动原文。只有原文的关联也可定位，失败保留来源并可重试。
- [ ] 教材自由滚动不移动图；分屏调整和窗口变化保持页内位置与图视野。
- [ ] 关闭、隐藏和重开保留会话上下文及草稿；两视图关闭后仍有恢复入口。
- [ ] 窄屏可切换视图，键盘可调分隔条并操作关闭与返回；焦点有有效落点。
- [ ] 原有关联返回、分组条目和方法开合继续有效；刷新延续现有教材续读，不新增图布局持久化。
- [ ] 浏览器完成跨章定位、调整宽度、关闭重开、窄屏切换和失败路径；06 完成后补走已确认的“教材 → 图 → 笔记链接 → 分屏定位 → 刷新恢复”整条路径，此补验不阻塞本票的独立实现。

规格覆盖：US9–14、35、37；T11–14。可与 04–06 并行；整条路径由最后完成的相关任务交付时补验，不另设纯测试任务。
