## 当前实现

- `src/app/App.tsx` 持有唯一的 `useBookContent()`；切换书架和阅读页不卸载认证、默认内容及个人快照。保留 02 的启动状态与成功导航记录、03 的移出／撤销回调。仅在已确认放弃受保护旧账号草稿并返回书架时调用现有显式 refresh，解除阻塞并加载当前账号；普通返回不无条件重读。
- `src/app/Shelf.tsx` 增加账号及内容状态插槽，顶部“添加教材”旁复用现有 `AccountControl`；加载、错误和重试可见。按 root 要求用 Set 去除相同阅读错误提示。教材菜单、信息、移出、撤销与版本身份逻辑保留。
- `src/reader/Reader.tsx` 接收 `content: BookContent`，不再创建另一份 hook；保留阅读器内账号动作与草稿保护。个人入口排除 draftOwner 阻塞；默认笔记在当前账号加载完成后开放，受保护旧草稿保持原编辑器。
- `src/reader/useBookContent.ts` 保存回调绑定其创建时的账号和会话代次，提交前后检查；外部换号保留最初 draftOwner 并提示邮箱或 ID，旧请求和旧草稿重试均不能采用新账号。导出 BookContent 类型。
- `src/reader/MarkdownEditor.tsx` 在 CodeMirror 原生编辑事件中立即标记 data-dirty，覆盖 React 提交前发生账号变化的窗口。
- `src/reader/AccountControl.css` 提高模式切换按钮选择器优先级，避免“发送登录邮件”和“测试账号登录”挤成相邻文本。没有新增登录方式、表、同步 API 或后端服务。
- SPEC R13、DESIGN、ARCHITECTURE、README 已按当前实现更新，保留 02／03 的启动与管理说明。
