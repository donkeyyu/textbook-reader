# 02: 重新打开后继续上次阅读

**What to build:** 让读者刷新或重新打开后回到同一原页区域，保留已保存笔记。

**Blocked by:** None (can start immediately)

**Spec:** [教材预习与复习规格](../spec.md) — B1–B4；用户故事8–14。

## Acceptance criteria

- [x] 首次访问从封面开始；稳定阅读后刷新和重新打开自动恢复文件页序及页内相对位置；尺寸变化后仍可见原段落附近。
- [x] 阅读记录按教材身份隔离，记录格式版本并校验；损坏、失配或无效记录回到封面且不崩溃。
- [x] 恢复完成后才开始记录新位置，不以初始化封面覆盖历史；写入节流，页面隐藏或离开前尽力保存。
- [x] 记录读写失败以非阻断提示说明，不重复弹窗；个人笔记及补充与阅读记录隔离，原有数据不受损。
- [x] 刷新只恢复原页，不恢复面板、方法状态、关联历史或草稿；当前会话返回行为保持。若停在关联目标页，刷新恢复目标页。
- [x] 演示刷新、重新打开与跨尺寸恢复；复用定位和存储测试覆盖异常边界，完成受影响测试、类型检查与构建。

## Boundaries

复用现有模块与检查，无需广泛预重构。只修改本票责任范围，保留并行工作和既有未提交改动。产品票包含必要实现与验证，内容票包含审核、修订与展示核验，观察票包含真实记录和问题复核。范围限教材解读，不增加诊断、作业辅导或课外培训。
