# 03: 从教材补充进入可探索的完整图

**Blocked by:** 02：原有教材与个人内容迁入本地数据库后继续阅读编辑。

**What to build:** 从当前 supplement 打开 Pixi 图，当前节点居中，读者可平移、缩放、搜索并选择节点，在图旁阅读解读及默认关联。此阶段沿用现有教材跳转，自动分屏由 07 增加。

- [x] 一条 supplement 一节点；当前教材全部默认及已有个人节点进入图，包括孤立节点，同名不合并。
- [x] 当前节点以可读比例居中；无当前节点时可进入概览。类型颜色与可读取名称一致。
- [x] 按 DonQ 2026-10-26 的补充参照 family-tree：拖动平滑，选中节点及直接相连节点保持清晰，其余节点弱化；名称按缩放层级显隐，当前节点名称可读。用有连接及孤立节点、多档缩放实测并留存效果。
- [x] 平移、缩放、节点拖动和搜索选择可用；键盘有完整搜索与选择路径。
- [x] 参考 family-tree 的现有实现与效果，或实际可获取的 Obsidian 材料，调校连线距离、节点排斥、碰撞间距和布局收敛；密集区与孤立节点均能找到并选中，不把节点或标签挤成不可操作的一团。
- [x] 拖动节点时节点跟随指针、连线同步更新，邻近节点有连续的布局反馈；拖动不误触点击或画布平移，释放后平稳收敛，不突然重置全图或视野。具体参数以本册实测确定，不新增固定位置或跨刷新布局保存要求。
- [x] 标签随缩放适当显隐，选中或搜索目标仍可辨认；用密集节点、孤立节点及不同缩放比例验证拖动与距离，并记录所用参考、调校结果和短录屏或连续截图。
- [x] 默认关联保留方向和依据；只有原文的目标仍可跳转，不生成空节点。同位置多个补充不任意选一个。
- [x] 点击节点只切换解读，保持方法默认收起、Markdown 安全和草稿保护；隐藏教材入口不删除图节点。
- [x] 全册数据核验数量与身份；浏览器走通选择、默认关联、原文目标及键盘路径，记录性能观察的设备与数据量。

规格覆盖：US1–8、14、37；T1–3、T13–14。借鉴 family-tree 的渲染与布局交互，不复制家族模型。

依据：[详细规格](../spec.md)、[审查记录](../review.md)。规格中的实施建议仍是工程建议，不提升为用户已确认的技术选型。
