# 补充节点图增量更新规格

日期：2026-10-26

本规格承接 Obsidian 图视图逆向报告与当前实现的对照评审，限定为显示属性与拓扑分开更新、按稳定身份复用图中状态。DonQ 已确认沿用现有节点图用户操作入口验收，复用引用投影测试，不为测试新增公开图引擎接口。本轮交付规格；实现由关联任务承接。

## Problem Statement

学生在图中修改个人节点标题或保存引用后，应能继续辨认节点、阅读解读和操作图。当前实现把节点标题、类型以及节点和连线集合放在同一个变化签名中；签名变化就销毁全部节点图形并重建力模拟，仅沿用旧节点的位置。改名也会重新启动布局，速度和拖动固定状态不能随节点连续保留。

这使内容更新与布局调整相互牵连，增加不必要的对象创建，并可能打断读者对图中位置的记忆。现有代码证据支持这一结构问题；尚未测量本轮改造能减少多少耗时，不能预先承诺帧率提升。

## Solution

内容更新后，图只更新变化的部分。修改标题或显示类型时更新名称和颜色，保留节点位置、相机和正在进行的交互。新增或删除节点、连线时，以已有布局为起点调整并收敛，不重置全图。

保持现有全图、搜索、拖动、教材定位、关联查阅、草稿保护与分屏行为。图隐藏时不运行布局或绘制；重新打开时显示最新内容并保留会话视野。

## User Stories

1. 作为学生，我希望个人节点改名后图中名称更新且位置不变，以便继续辨认刚才阅读的节点。
2. 作为学生，我希望修改未增加或删除引用的正文后图保持稳定，以便专注于内容。
3. 作为学生，我希望数据重新读取但内容不变时图不重新排列，以便继续原来的探索。
4. 作为学生，我希望节点显示类型变化时只更新对应颜色，以便保持原有空间位置。
5. 作为学生，我希望新增个人节点后已有节点从当前位置继续调整，以便辨认新旧内容。
6. 作为学生，我希望删除个人节点后该节点及关联连线消失，以免误选已删除内容。
7. 作为学生，我希望新增个人引用后出现对应连线并平稳调整布局，以便理解新建立的联系。
8. 作为学生，我希望删除重复引用中的一处后连线继续存在，以便图准确反映剩余引用。
9. 作为学生，我希望双方互引时删除一个方向仍保留个人连线，以便图与已保存内容一致。
10. 作为学生，我希望删除最后一处个人引用后只移除该个人连线，以便保留独立的默认教材关联。
11. 作为学生，我希望新增或删除关联后直接邻居的强调同步更新，以便正确辨认当前联系。
12. 作为学生，我希望保存内容时保持缩放和平移位置，以便无需重新寻找阅读区域。
13. 作为学生，我希望拖动过程中收到内容更新时节点继续跟随指针，以便完成当前操作。
14. 作为学生，我希望正在拖动的节点被删除时拖动正常结束，以免画布卡在拖动状态。
15. 作为学生，我希望松开节点后布局继续平稳收敛，以便看清关联节点的位置。
16. 作为学生，我希望搜索结果使用更新后的名称且同名节点仍可区分，以便打开正确解读。
17. 作为学生，我希望选中、悬停和搜索强调不会额外启动布局，以便稳定地查看名称和连线。
18. 作为学生，我希望隐藏图后保存的变化在重开时正确显示，以便继续之前的视野。
19. 作为学生，我希望更新图时解读草稿、方法开合和教材位置不被重置，以便保持阅读连续性。
20. 作为学生，我希望空图、仅有孤立节点以及删除最后一个节点后仍可正常操作，以便继续添加或查找内容。
21. 作为学生，我希望键盘搜索选择和窄屏切换继续可用，以便使用原有方式阅读。

## Implementation Decisions

- 保留现有图数据投影、图视图和绘图 hook 的职责。图数据投影提供节点与两类连线；绘图模块管理可变布局状态、图形和相机。维持现有对阅读器的调用接口，不建立通用图引擎或新增可替换引擎层。
- 以教材、内容来源与节点 ID 组成的现有稳定身份匹配节点。标题、数组顺序或相同教材位置不作为节点身份；同名节点不合并。
- 分开判断显示属性变化和拓扑变化。显示属性包括标题和类型；拓扑包括节点身份集合和带类型的连线关系。仅输入数组顺序变化、等值对象重建或引用次数变化但图中连线未变化时，不重新启动布局。
- 默认连线保留方向，个人连线按现有无向配对语义处理；连线类型必须参与比较。同一对节点上的默认关联与个人引用独立存在。比较沿用投影结果的语义，不借此次改造合并原有默认关系或改变布局权重。
- 按节点身份复用现有布局节点及其圆点、强调环和标签。保留已有位置、速度与有效拖动固定坐标；标题更新只改文字，类型更新只改颜色及对应显示。已在运动的图可继续冷却，但属性更新不得额外加热或重置模拟。
- 节点和连线变化时更新已有模拟的数据。保留未删除节点的布局状态，为新增节点设置有效初始位置，移除已删除节点及失效连线，再按需恢复布局。不得重新执行首次全图初始化。新增节点的初始位置和恢复布局的具体参数由实现时按真实教材数据选择。
- 保留现有批量绘制连线的方式，不要求为每条边建立持久 Pixi 对象。复用对象不等于冻结屏幕像素；真实拓扑变化后允许力布局带动原有节点移动并收敛。
- 邻接关系、选中强调、搜索强调与命中检测使用最新节点和连线。标签修改后重新计算必要的显示与避让，不因名称改变留下旧命中对象或旧搜索结果。
- 更新过程保留相机变换。已有显式“全图”“当前节点”、搜索选择与首次进入的定位行为继续生效；内容刷新自身不能触发这些动作。
- 拖动中的节点仍存在时保留该手势与固定状态；该节点被删除时结束手势并释放指针捕获。其他节点的增删不能把当前拖动转成点击或画布平移。选中节点被删除时遵循现有阅读器删除流程，不保留已失效的图对象。
- 图隐藏期间可更新数据，但不得因更新启动布局或绘制。重开后按最新数据恢复，已有节点保持视野；属性更新后的已冷却布局保持静止。隐藏时中断的拖动仍需正常收尾。
- 图资源按挂载周期管理，事件监听、模拟与帧请求不能随每次数据更新重复累积。删除节点及时释放其图形资源，卸载时清理模拟、事件和绘图资源。
- 不修改存储结构、账号隔离、正文解析或引用绑定协议。只消费已接受的保存快照，不以未保存草稿生成连线。

## Testing Decisions

- **主要测试入口已获 DonQ 确认：现有节点图的用户操作路径。** 从阅读器打开图，实际改名、保存引用、增删节点、拖动和切换视图。复用现有浏览器图检查、分屏检查及个人引用检查方式，不新增生产环境测试接口。
- 好的测试验证用户可见行为和领域语义：内容更新正确、视野连续、引用不丢失、手势可完成、隐藏不消耗布局帧。不要用私有变量名、effect 数量、精确力参数或整幅随机布局截图作为契约。
- 在已冷却布局中修改标题、修改不影响引用的正文、重复加载等值数据和调整输入顺序，核对节点位置与相机不变、名称正确且没有额外布局启动。更新顺序的场景可使用隔离测试数据；不新增排序界面。
- 在仍运动的布局中更新标题，核对运动连续且没有重置或额外加热。不能要求运动中的节点与更新前坐标逐像素相同。
- 新增和删除节点、增删连线时核对现有布局未回到初始化位置，连线和强调正确，并最终收敛。覆盖有连接节点、孤立节点、空图和删除最后一个节点。
- 实际拖动期间更新标题、增删其他节点，以及删除当前拖动节点，核对指针捕获收尾、节点跟随、松开后收敛且不误触选择。配合连续截图或短录屏确认过程。
- 隐藏图后分别执行属性更新和拓扑更新，观察无绘制、无布局 tick；重开时显示最新内容，视野保留。沿用已有隔离浏览器临时探针方式，测试后移除探针。
- 复用个人引用投影测试，保留重复引用、互引、最后一处删除、默认边独立、改名不丢绑定、失效目标不误连等案例。只有实现改变相关数据逻辑时才补充对应测试，不复制已有断言。
- 完整回归路径覆盖搜索与键盘选择、选中及邻居强调、缩放标签、解读草稿保护、显式定位教材、关联返回、桌面分屏和窄屏切换。图更新不能改变教材位置或强制重置面板。
- 对反复更新及关闭重开进行资源检查，确认没有重复事件响应、持续增加的已删除图形或空闲布局活动。对象复用可在代码审查及隔离探针中检查，不为此暴露公开接口。
- 实现前后在同一设备、浏览器、数据量和操作条件下记录改名、增删连线与拖动的观察结果。首次打开耗时可作为未来 Worker 决策的基线，但其优化不是本票通过条件。不承诺固定 FPS，不把自动化采样当作真实终端性能保证。
- 实现交付须通过受影响测试、类型检查、构建和上述浏览器路径。记录源码版本、数据量、证据与未验证范围；本次规格编写不代表这些验收已经通过。

## Out of Scope

- Worker 迁移、WASM、SharedArrayBuffer、第二套布局引擎及并行计算协议。
- 首次同步布局预计算的专项优化、分批创建图形、节点与边的视口裁剪、空间索引和按文档增量解析缓存。
- 局部图、搜索筛除节点、连接度改变节点大小、分组聚合力及力参数设置界面。
- 未解析引用自动生成空白节点、合并同名补充节点或将个人引用改成默认教材关联。
- 跨刷新布局保存、固定节点产品功能、动态主题切换功能和新增默认内容编辑能力。类型更新仅覆盖现有数据输入，不新增编辑入口。
- 数据库迁移、账号及保存流程重构、学习效果评估和新终端支持。

## 实施中确认的追加范围（2026-10-26）

DonQ 要求“鼠标停在节点上 100ms 后再聚焦节点，而不是滑过就聚焦”。行为要求已更新到 SPEC R12；02 实现并验证悬停停留门槛，03 接手其生命周期。计时中的节点身份稳定，属性刷新不取消有效停留；删除目标、开始拖动、隐藏、失焦或卸载时取消待触发聚焦。Ctrl 预览跟随已确认的悬停目标，静止按松 Ctrl 仍即时响应。

浏览器验证补充快速滑过、满门槛停留、同节点内移动、换节点、隐藏／拖动时取消和静止 Ctrl。记录实际事件顺序与时间，允许浏览器调度晚于门槛，不把固定精确绘制时间作为契约。
